## 2026年11月12日

* テキストファイル、Markdownドキュメント、チャット、統合ブラウザタブを作成するためのエディタータブバーの **+** メニューを追加します。 _[#347849: Experimental new tab (+) button in the editor tab bar](https://github.com/microsoft/vscode/issues/347849)_
* コードの生成、チャットの開始、言語の選択、または未保存ファイルを別のエディターで再度開くためのアクションを追加します。 _[#347848: Experiment: show a list of actions in the hint of new untitled files](https://github.com/microsoft/vscode/issues/347848)_
* チャットに貼り付けられた画像に、可能な場合はそのソースファイルにちなんだ名前を付けます。 _[#347828: Chat: name pasted images after their source file](https://github.com/microsoft/vscode/issues/347828)_
* 兄弟プロジェクト間の移動を減らすため、Agentsウィンドウの **Open Folder** ダイアログを、選択したローカルフォルダーの親フォルダーから開始します。 _[#335652: Choose Folder: Make parent folder of current folder the starting point](https://github.com/microsoft/vscode/issues/335652)_
* ツールバーメニューを使用して、Agentsウィンドウのクリーンアップエディターでワークツリーをフィルターおよび並べ替えます。 _[#347138: Controls area for worktree cleanup could use some design love](https://github.com/microsoft/vscode/issues/347138)_
* HTMLおよびCSSファイルの1行の `#region` コメントに対して、ミニマップのセクションヘッダーを表示します。 _[#210637: Minimap section headers are not shown for regions in HTML and CSS](https://github.com/microsoft/vscode/issues/210637)_
* [ローカル拡張機能の開発](https://code.visualstudio.com/api/advanced-topics/using-proposed-api)中に、エディターおよびAgentsウィンドウのタイトルバーにボタンを提供する、提案中の `contribTitleBar` API を追加します。 _[#347839: Proposed API: let extensions contribute buttons to the title bar of the editor and Agents windows](https://github.com/microsoft/vscode/issues/347839)_
* 実験的な **AI Usage Statistics** ステータスバーウィジェットを削除します。 _[#340001: Remove the AI Usage Statistics widget](https://github.com/microsoft/vscode/issues/340001)_

## 2026年11月11日

* 両方のウィンドウで同じエージェントホストを使用している場合に、Agentsウィンドウと、WSL、Remote - SSH、またはDev Containerのエディターウィンドウの間でエージェントセッションを共有します。 _[#346859: Share agent host sessions between the Agents Window and WSL, SSH and Dev Container editor windows](https://github.com/microsoft/vscode/issues/346859)_
* 互換性のある受信トレイカテゴリ間でセッションをドラッグして、ピン留め、保持、クリア、アーカイブ、または再開します（実験的）。 _[#346934: Inbox mode: Sessions cannot be dragged between groups](https://github.com/microsoft/vscode/issues/346934)_
* すべてのWebリンクを統合ブラウザで開くことを有効にします。 _[#316528: Option to open all links in Integrated Browser](https://github.com/microsoft/vscode/issues/316528)_

## 2026年11月10日

* 受信トレイモードの対象セッションに対するインラインの **Merge Pull Request** アクションを追加します（実験的）。 _[#346936: Inbox mode: Ready to Merge sessions have no inline Merge action](https://github.com/microsoft/vscode/issues/346936)_
* **Inbox** を表示したまま、受信トレイモードの空のカテゴリを非表示にします（実験的）。 _[#346938: Inbox mode: Empty sections take up too much vertical space](https://github.com/microsoft/vscode/issues/346938)_
* AgentsウィンドウでCompare Models（プレビュー）の親チャットにマウスオーバーして、元の設定を確認します。 _[#347109: Model compare: show original settings on hover of the parent chat](https://github.com/microsoft/vscode/issues/347109)_
* セッション復元のリマインダーを維持しながら、ワークツリークリーンアップの確認を短縮します。 _[#347134: Worktree cleanup confirmation is unncessarily wordy](https://github.com/microsoft/vscode/issues/347134)_
* Markdownエディターでの折りたたみ可能な `<details>` セクションのサポートを追加します（実験的）。 _[#347433: Markdown editor: render `<details>`/`<summary>` as collapsible sections](https://github.com/microsoft/vscode/issues/347433)_
* チャット入力の上にピン留めされたチャットファイルを表示するサポートを追加します（実験的）。 _[#345427: Let extensions dock views above the chat input](https://github.com/microsoft/vscode/issues/345427)_
* VS Codeペットを非表示にするコンテキストメニューオプションを追加します（実験的）。 _[#346510: Remove option for vscode-pet](https://github.com/microsoft/vscode/issues/346510)_
* ワークスペースおよび実行環境によって受信トレイセッションをフィルターします（実験的）。 _[#347488: Add workspace and environment scope pickers to Inbox](https://github.com/microsoft/vscode/issues/347488)_
