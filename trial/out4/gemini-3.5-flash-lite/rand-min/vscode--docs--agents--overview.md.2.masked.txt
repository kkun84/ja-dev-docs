# ⟦C5G3⟧でのAIを活用したビルド

⟦7PJS⟧では、タスクに応じて必要なだけAIを活用できます。入力に応じたサジェスト機能の利用、コード、テスト、デバッガーの横で動作するエージェントとの協業、あるいは⟦6Z4N⟧でのプロジェクトを跨いだタスクの調整などを行います。作業の進捗に合わせてこれらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦2K2S⟧、⟦527R⟧、または⟦ESMG⟧のエージェントハーネスを利用します。ハーネスは、モデル周辺のツールやワークフローを提供します。カスタマイズやプラグインを使用すると、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェース間でエージェントの作業を引き継ぐことができます。⟦RJ5S⟧を介して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](/docs/agents/concepts/agents.md)は、モデルとツールを使用して関連コードを見つけ、変更を加え、チェックを実行します。⟦GVAS⟧と⟦FGDS⟧の両方でエージェントが実行されます。目標の設定、作業の誘導、結果の確認を行います。

日常的な作業には、プロンプトを[自動化](/docs/agents/run/automations.md)として保存します。スケジュールに従ってローカルで実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリの作業にクラウド自動化 `feature(cloud-automations)` を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

フォーカスした編集を行うには、コードから離れることなく[インラインチャット](/docs/chat/inline-chat.md)を使用します。特定のタスクの機能を比較するには、[AI機能早見表](/docs/agents/reference/ai-features-cheat-sheet.md#choose-a-feature)を使用します。

## モデル、エージェント、ツールの選択

初めてのエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用](/docs/agents/quickstart.md)します。ニーズの変化に応じて、以下の選択肢を適宜変更できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦VSJN⟧を通じて[複数のプロバイダーのモデル](/docs/agent-customization/language-models.md)を選択するか、独自の[APIキー（BYOK）](/docs/agent-customization/language-models.md#bring-your-own-language-model-key)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](/docs/agents/run/agent-harnesses.md#compare-agent-harnesses)に基づいて、⟦V9BH⟧、⟦FWW7⟧、または⟦68B3⟧から選択します。 |
| **アクセスと課金** | 既存の⟦P7AQ⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](/docs/agents/run/agent-harnesses.md#requirements-and-setup)を確認してください。 |
| **カスタマイズ** | [プラグイン](/docs/agent-customization/agent-plugins.md)、[プロジェクト指示](/docs/agents/guides/customize-copilot-guide.md)、[スキル](/docs/agent-customization/agent-skills.md)を使用してエージェントを調整します。[Model Context Protocol（MCP）サーバー](/docs/agent-customization/mcp-servers.md)を介して外部ツールを接続します。 |

## インターフェースとマシンの間での継続

継続性とは、最初からやり直すことなく、サポートされているインターフェースやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境をホスト側に維持したまま、エージェントと対話する場所を選択できます。セッションのサポートや要件は、ハーネスや接続先によって異なります。

| 作業を行いたい場所 | ここから開始 |
|------------------------|------------|
| **⟦3H7W⟧のアプリやデバイス間** | [⟦9VZT⟧](/docs/agents/run/remote-agent-sessions.md#github-environments) `feature(github-environments)` を使用して開発マシンを登録し、⟦VTWR⟧、⟦QQVN⟧、⟦YQVX⟧、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](/docs/agents/run/cloud-sandbox-sessions.md) `feature(cloud-sessions)` を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦8EVX⟧** | ⟦924Y⟧で⟦SA6X⟧、⟦BTEX⟧、または⟦9Z5J⟧のエージェントハーネスを使用し、[インターフェース間でセッションを継続](/docs/agents/run/sessions/manage-sessions.md#continue-between-the-chat-view-and-agents-window)します。 |
| **別マシンの⟦AC9V⟧** | [SSH](/docs/agents/run/remote-agent-sessions.md#connect-via-ssh)または[開発用トンネル](/docs/agents/run/remote-agent-sessions.md#connect-via-dev-tunnel)を介した⟦4KQ4⟧固有のリモート接続を使用します。開発用トンネルは、[ブラウザーベースの⟦ZBGC⟧](/docs/agents/run/remote-agent-sessions.md#use-the-agents-window-in-the-browser)もサポートしています。 |

自分のマシンで実行されるセッションについては、ホストを稼働させ、アクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業のためにクラウドセッションを開始し、後からそのセッションを再び開いて継続します。

自身のプライベートリポジトリを使用して、[⟦CM84⟧でクラウドエージェントタスクを開始し、⟦9D7P⟧で継続します](/docs/agents/cloud-continuity-tutorial.md)（実験的機能）。

ツールの実行場所とモデルのホスト先は、個別に選択できます。エージェントは、ホストされているプロバイダーにモデルのリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AIは誤ったコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに反映させるかの最終決定権は、常にユーザーにあります。

* **統合前のレビュー。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認し、結果を検証](/docs/agents/run/review-code-edits.md)してください。
* **アクションの制御と作業の誘導。** [権限と承認](/docs/agents/run/approvals.md)を使用して、どのアクションを確認必須にするかを決定します。[リクエストの誘導や停止](/docs/chat/chat-overview.md#send-messages-while-a-request-is-running)を行うことはできますが、停止しても、完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムやネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](/docs/agents/run/agent-sandboxing.md)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティベースライン](/docs/agents/run/security.md#recommended-security-baseline)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](/docs/enterprise/manage-ai-settings.md)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](/docs/agents/agent-troubleshooting/faq.md#agents-are-not-available-in-chat)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](/docs/configure/accessibility/accessibility.md#accessible-view)の使用方法を参照してください。
