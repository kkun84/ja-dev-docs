## GitHubでのアクセス権限について

⟦A3D2⟧

ロールの仕組みはアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦NKKG⟧)をご覧ください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_の2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦GBXA⟧)をご覧ください。

## 組織アカウント

組織のメンバーには、_オーナー_⟦CE5R⟧、_請求管理者_⟦FA8Y⟧、または_メンバー_のロールを設定できます。オーナーは組織に対する完全な管理アクセス権を持ち⟦C8F4⟧、請求管理者は請求設定を管理できます⟦95NJ⟧。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下をご覧ください。
* [AUTOTITLE](⟦7WWR⟧)
* [AUTOTITLE](⟦AQXG⟧)
* [AUTOTITLE](⟦XDFS⟧)

## エンタープライズアカウント

エンタープライズアカウントには、ユーザーのエンタープライズ設定へのアクセスを定義する事前定義された一連のロールがあります。また、カスタムエンタープライズロールを作成して、独自のきめ細かな権限セットを定義することもできます。

詳細については、GitHub Enterprise Cloudドキュメントの⟦WP6Q⟧[AUTOTITLE](⟦9PQX⟧)⟦28AS⟧[AUTOTITLE](⟦WCMJ⟧)⟦RB8J⟧をご覧ください。
