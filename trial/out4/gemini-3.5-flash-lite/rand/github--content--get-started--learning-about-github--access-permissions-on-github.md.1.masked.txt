## ⟦4ADM⟧でのアクセス権限について

⟦7D54⟧

ロールの動作はアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦HWY3⟧)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_という2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦MD3J⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_オーナー_⟦F9S4⟧、_請求管理者_⟦F7B5⟧、または_メンバー_のロールを設定できます。オーナーは組織に対する完全な管理者アクセス権を持ち⟦4A6C⟧、請求管理者は請求設定を管理できます⟦35KB⟧。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦2GE8⟧)
* [AUTOTITLE](⟦5D9C⟧)
* [AUTOTITLE](⟦YHZ9⟧)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセスを定義する事前定義された一連のロールがあります。また、独自の細かい権限セットを定義するカスタムエンタープライズロールを作成することもできます。

詳細については、⟦BG3W⟧ドキュメント⟦HHGW⟧の⟦96EY⟧[AUTOTITLE](⟦6CMM⟧)⟦[AUTOTITLE](⟦9Y2D⟧)⟦6T85⟧を参照してください。
