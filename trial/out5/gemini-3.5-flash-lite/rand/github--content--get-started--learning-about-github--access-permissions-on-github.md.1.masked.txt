## パーソナルアカウント

パーソナルアカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_という2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦6T85⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_オーナー_⟦7D54⟧、_請求マネージャー_⟦F9S4⟧、または_メンバー_のロールを設定できます。オーナーは組織に対する完全な管理アクセス権を持ち⟦F7B5⟧、請求マネージャーは請求設定を管理できます⟦4A6C⟧。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦HWY3⟧)
* [AUTOTITLE](⟦MD3J⟧)
* [AUTOTITLE](⟦2GE8⟧)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセスを定義する、事前定義されたさまざまなロールがあります。また、カスタムのエンタープライズロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、GitHub Enterprise Cloudドキュメント⟦96EY⟧の⟦35KB⟧[AUTOTITLE](⟦5D9C⟧) [AUTOTITLE](⟦YHZ9⟧)⟦BG3W⟧を参照してください。
