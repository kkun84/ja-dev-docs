## <x id="CFFA"/> のアクセス権限について

<x id="CQAD"/>

ロールの動作はアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](<x id="8Y9B"/>) を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリ所有者_ と _コラボレーター_ の2つの権限レベルがあります。詳細については、[AUTOTITLE](<x id="K43A"/>) を参照してください。

## 組織アカウント

組織のメンバーには、_所有者_<x id="J2EZ"/>、_請求管理者_<x id="7KC9"/>、または _メンバー_ のロールを割り当てることができます。所有者は組織に対する完全な管理者アクセス権を持ち<x id="QVHY"/>、請求管理者は請求設定を管理できます<x id="SKCS"/>。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](<x id="WBNY"/>)
* [AUTOTITLE](<x id="HPMW"/>)
* [AUTOTITLE](<x id="XPKA"/>)

## 企業アカウント

企業アカウントには、Enterprise 設定へのユーザーのアクセスを定義するさまざまな事前定義済みロールがあります。また、独自のきめ細かなアクセス許可のセットを定義するために、カスタム Enterprise ロールを作成することもできます。

詳細については、<x id="MVBR"/> ドキュメント<x id="VNCN"/>の <x id="S9YR"/>[AUTOTITLE](<x id="H345"/>) と [AUTOTITLE](<x id="7QPD"/>)<x id="JSHK"/> を参照してください。
