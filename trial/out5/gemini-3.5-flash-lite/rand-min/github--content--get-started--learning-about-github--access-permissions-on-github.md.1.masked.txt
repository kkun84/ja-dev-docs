## GitHubでのアクセス権限について

⟦4ADM⟧

アカウントの種類によって、ロールの仕組みは異なります。アカウントの詳細については、[AUTOTITLE](/get-started/learning-about-github/types-of-github-accounts)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_repository owner_ と _collaborators_ という2つの権限レベルがあります。詳細については、[AUTOTITLE](/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository)を参照してください。

## 組織アカウント

組織のメンバーには、_owner_⟦7D54⟧、_billing manager_⟦F9S4⟧、または _member_ のロールを割り当てることができます。ownerは組織に対する完全な管理者アクセス権を持ち⟦F7B5⟧、billing managersは請求設定を管理できます⟦4A6C⟧。memberは、それ以外のすべてのユーザーのデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization)
* [AUTOTITLE](/organizations/managing-user-access-to-your-organizations-repositories/managing-repository-roles/repository-roles-for-an-organization)
* [AUTOTITLE](/organizations/organizing-members-into-teams/about-teams)

## エンタープライズアカウント

エンタープライズアカウントには、エンタープライズ設定へのユーザーのアクセスを定義する、あらかじめ定義されたさまざまなロールがあります。また、カスタムのエンタープライズロールを作成して、独自の詳細な権限セットを定義することもできます。

詳細については、GitHub Enterprise Cloudドキュメントの⟦35KB⟧[AUTOTITLE](/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦96EY⟧[AUTOTITLE](/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦BG3W⟧を参照してください。
