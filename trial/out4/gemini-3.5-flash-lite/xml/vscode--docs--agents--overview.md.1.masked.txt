# Build with AI in <x id="9PSS"/>

<x id="GH8K"/>では、タスクに応じて必要なだけのAIを活用できます。入力に応じたサジェスト機能の利用、コード、テスト、デバッガーの横で動作するエージェントとの協業、あるいは<x id="D5RA"/>でのプロジェクトをまたいだタスクの調整を行います。作業の進捗に合わせて、これらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、<x id="XZRD"/>、<x id="4F22"/>、または<x id="E7W3"/>のエージェントハーネスを使用します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。<x id="DYCR"/>を使用して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](<x id="42YZ"/>)は、モデルとツールを使用して関連コードを検索し、変更を加え、チェックを実行します。<x id="V5DD"/>と<x id="SZKK"/>の両方でエージェントが実行されます。あなたが目標を設定し、作業を誘導し、結果を確認します。

定型作業の場合は、プロンプトを[自動化(automation)](<x id="Z49M"/>)として保存します。スケジュールに従ってローカルで実行するか、クラウド自動化<x id="T575"/>を使用して、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業を実行します。定期的な作業を有効にする前に、手動での実行を確認してください。

集中した編集を行うには、コードから離れることなく[インラインチャット](<x id="RYG2"/>)を使用します。特定のタスクの機能を比較するには、[AI機能の早見表](<x id="TBCE"/>)を使用します。

## モデル、エージェント、ツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](<x id="EFRB"/>)。ニーズの変化に合わせて、以下の選択肢を調整できます。

| 選択項目 | オプション |
|--------|---------|
| **モデル** | <x id="VZVN"/>経由で[複数のプロバイダーのモデル](<x id="EC2P"/>)を選択するか、独自の[APIキー(BYOK)](<x id="DPSY"/>)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | その[ツールとワークフロー](<x id="SX43"/>)に基づいて、<x id="65BQ"/>、<x id="7JVE"/>、または<x id="HMYB"/>から選択します。 |
| **アクセスと課金** | 既存の<x id="P9XA"/>プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](<x id="Z8TC"/>)を確認してください。 |
| **カスタマイズ** | [プラグイン](<x id="VW8W"/>)、[プロジェクト指示](<x id="WZPZ"/>)、[スキル](<x id="97CZ"/>)を使用してエージェントを調整します。[Model Context Protocol (MCP) サーバー](<x id="H7YT"/>)を通じて外部ツールを接続します。 |

## インターフェイスとマシン間での継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境をホスト側に維持したまま、エージェントと対話する場所を選択します。セッションのサポート状況や要件は、ハーネスや接続先によって異なります。

| 作業場所 | ここから開始 |
|--------|------------|
| **<x id="TSN7"/>アプリとデバイス間で** | [<x id="J429"/>](<x id="R5Q7"/>) <x id="CC9N"/>を使用して開発用マシンを登録し、<x id="V2XD"/>、<x id="ZXWE"/>、<x id="5AB7"/>、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **マネージドクラウドコンピュート上で** | 自分のマシンをオンラインに維持することなくインタラクティブなエージェント作業を行うには、[クラウドセッション](<x id="WG4J"/>) <x id="SQZS"/>を使用します。既存のクラウドセッションを再度開いて会話を続けます。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは<x id="HT2B"/>** | <x id="D524"/>で<x id="BYAW"/>、<x id="7XK2"/>、または<x id="9FWR"/>のエージェントハーネスを使用し、[インターフェイス間でセッションを継続](<x id="VDBP"/>)します。 |
| **別マシンの<x id="7Y62"/>** | [SSH](<x id="XQBS"/>)または[開発用トンネル](<x id="Q7R5"/>)による<x id="Y32D"/>固有のリモート接続を使用します。開発用トンネルは、[ブラウザベースの<x id="BNKT"/>](<x id="CKPF"/>)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを稼働状態にしてアクセス可能な状態に維持してください。クラウドセッションでは、代わりにマネージドコンピュートが使用されます。クラウドでの作業のためにクラウドセッションを開始し、そのセッションを再度開いて継続します。

独自のプライベートリポジトリを使用して、[<x id="8QGQ"/>でクラウドエージェントタスクを開始し、<x id="6ZA6"/>で継続します](<x id="EYWP"/>)（実験的機能）。

ツールが実行される場所とモデルがホストされる場所は、個別の選択項目です。エージェントは、ホストされたプロバイダーにモデルリクエストを送信しながら、マシン上でファイルを編集できます。

## 制御の維持

AIは不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに反映させるかの最終的な責任はユーザーにあります。

* **統合前の確認。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認し、結果を検証します](<x id="4MK8"/>)。
* **アクションの制御と作業の誘導。** [権限と承認](<x id="CBV8"/>)を使用して、確認を必要とするアクションを決定します。[リクエストを誘導または停止](<x id="2VKY"/>)できますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Gitワークツリーによってコードの変更は分離されますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](<x id="SDDK"/>)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](<x id="SZBP"/>)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](<x id="4W9Y"/>)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](<x id="VSTJ"/>)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](<x id="N6ZT"/>)の使用方法を確認してください。
