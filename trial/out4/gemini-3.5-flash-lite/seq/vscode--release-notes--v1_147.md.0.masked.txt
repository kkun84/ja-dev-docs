## 2026年11月12日

* テキストファイル、Markdownドキュメント、チャット、統合ブラウザタブを作成するためのエディタータブバーの **+** メニューを追加します。 _[#347849: Experimental new tab (+) button in the editor tab bar](⟦U17⟧)_
* コードの生成、チャットの開始、言語の選択、または別のエディターでの無題ファイルの再オープンを行うアクションを追加します。 _[#347848: Experiment: show a list of actions in the hint of new untitled files](⟦U18⟧)_
* チャットに貼り付けられた画像に、可能な場合はそのソースファイルにちなんだ名前を付けます。 _[#347828: Chat: name pasted images after their source file](⟦U19⟧)_
* 兄弟プロジェクト間での移動を減らすため、Agents ウィンドウの **Open Folder** ダイアログを、選択されたローカルフォルダーの親から開始します。 _[#335652: Choose Folder: Make parent folder of current folder the starting point](⟦U20⟧)_
* ツールバーメニューを使用して、Agents ウィンドウのクリーンアップエディターでワークツリーをフィルターおよび並べ替えます。 _[#347138: Controls area for worktree cleanup could use some design love](⟦U21⟧)_
* HTML および CSS ファイルの単行の ⟦I8⟧ コメントのミニマップセクションヘッダーを表示します。 _[#210637: Minimap section headers are not shown for regions in HTML and CSS](⟦U22⟧)_
* [ローカル拡張機能の開発](⟦U23⟧)中に、エディターおよび Agents ウィンドウのタイトルバーにボタンを提供するための提案された ⟦I9⟧ API を追加します。 _[#347839: Proposed API: let extensions contribute buttons to the title bar of the editor and Agents windows](⟦U24⟧)_
* 実験的な **AI Usage Statistics** ステータスバーウィジェットを削除します。 _[#340001: Remove the AI Usage Statistics widget](⟦U25⟧)_

## 2026年11月11日

* 両方のウィンドウで同じエージェントホストを使用している場合に、Agents ウィンドウと WSL、Remote - SSH、または Dev Container エディターウィンドウの間でエージェントセッションを共有します。 _[#346859: Share agent host sessions between the Agents Window and WSL, SSH and Dev Container editor windows](⟦U26⟧)_
* 互換性のある受信トレイカテゴリ間でセッションをドラッグして、ピン留め、保持、クリア、アーカイブ、または再開します (実験的)。 _[#346934: Inbox mode: Sessions cannot be dragged between groups](⟦U27⟧)_
* すべてのウェブリンクを統合ブラウザで開くことを有効にします。 _[#316528: Option to open all links in Integrated Browser](⟦U28⟧)_

## 2026年11月10日

* 受信トレイモードの対象セッションに対して、インラインの **Merge Pull Request** アクションを追加します (実験的)。 _[#346936: Inbox mode: Ready to Merge sessions have no inline Merge action](⟦U29⟧)_
* **Inbox** を表示したまま、受信トレイモードで空のカテゴリを非表示にします (実験的)。 _[#346938: Inbox mode: Empty sections take up too much vertical space](⟦U30⟧)_
* Agents ウィンドウで Compare Models (プレビュー) の親チャットにマウスオーバーして、その元の設定を表示します。 _[#347109: Model compare: show original settings on hover of the parent chat](⟦U31⟧)_
* セッション復元のリマインダーを維持しながら、ワークツリークリーンアップの確認メッセージを短縮します。 _[#347134: Worktree cleanup confirmation is unncessarily wordy](⟦U32⟧)_
* Markdown エディターでの折りたたみ可能な ⟦I10⟧ セクションのサポートを追加します (実験的)。 _[#347433: Markdown editor: render ⟦I11⟧/⟦I12⟧ as collapsible sections](⟦U33⟧)_
* チャット入力の上にピン留めされたチャットファイルを表示するサポートを追加します (実験的)。 _[#345427: Let extensions dock views above the chat input](⟦U34⟧)_
* VS Code ペットを非表示にするコンテキストメニューオプションを追加します (実験的)。 _[#346510: Remove option for vscode-pet](⟦U35⟧)_
* 受信トレイセッションをワークスペースおよび実行環境でフィルターします (実験的)。 _[#347488: Add workspace and environment scope pickers to Inbox](⟦U36⟧)_
