# ⟦L1:variables.product.prodname_vscode_shortname⟧でのAIによるビルド

⟦L2:variables.product.prodname_vscode⟧では、タスクに必要な分だけAIを活用できます。入力に応じたサジェスチョンを受け取る、コード、テスト、デバッガーの横でエージェントと協業する、あるいは⟦L3:variables.copilot.agents_window⟧でプロジェクトをまたいでタスクを調整するといったことが可能です。作業の変化に合わせてこれらのアプローチを組み合わせます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦L4:variables.product.prodname_copilot_short⟧、⟦L5:variables.product.prodname_anthropic_claude_short⟧、または⟦L6:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを利用します。ハーネスは、モデルの周囲にあるツールやワークフローを提供します。カスタマイズやプラグインを使用すると、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦L7:variables.copilot.github_environments⟧を通じて自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](⟦U40⟧)は、モデルとツールを使用して関連するコードを見つけ、変更を加え、チェックを実行します。⟦L12:variables.copilot.chat_view⟧と⟦L13:variables.copilot.agents_window⟧の両方でエージェントが実行されます。ユーザーが目標を設定し、作業をガイドし、結果を確認します。

定型的な作業には、プロンプトを[自動化](⟦U41⟧)として保存します。ローカルでスケジュール実行するか、クラウド自動化⟦I34⟧を使用して、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業を実行します。定期的な作業を有効にする前に、手動実行を確認してください。

特定の編集には、コードから離れることなく[インラインチャット](⟦U42⟧)を使用します。特定のタスクの機能を比較するには、[AI機能のチートシート](⟦U43⟧)を使用します。

## モデル、エージェント、ツールを選択する

最初のエージェントタスクでは、すべてのオプションを設定することなく[クイックスタートを使用します](⟦U44⟧)。ニーズの変化に合わせて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦L14:variables.product.prodname_copilot⟧を通じて[複数のプロバイダーのモデル](⟦U45⟧)を選択するか、独自の[APIキー（BYOK）](⟦U46⟧)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](⟦U47⟧)に基づいて、⟦L15:variables.product.prodname_copilot_short⟧、⟦L16:variables.product.prodname_anthropic_claude_short⟧、または⟦L17:variables.product.prodname_openai_codex_short⟧から選択します。 |
| **アクセスと課金** | 既存の⟦L18:variables.product.prodname_copilot⟧プラン、サポートされているプロバイダーのアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦U48⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦U49⟧)、[プロジェクトの指示](⟦U50⟧)、[スキル](⟦U51⟧)を使用してエージェントを調整します。[Model Context Protocol（MCP）サーバー](⟦U52⟧)を通じて外部ツールを接続します。 |

## インターフェイスとマシンの間で継続する

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境はホスト上に維持したまま、エージェントと対話する場所を選択します。セッションのサポート状況と要件は、ハーネスや宛先によって異なります。

| 作業を行いたい場所 | ここから開始 |
|------------------------|------------|
| **⟦L19:variables.product.prodname_copilot_short⟧のアプリとデバイス間** | [⟦L20:variables.copilot.github_environments⟧](⟦U53⟧) ⟦I35⟧を使用して開発マシンを登録し、⟦L21:variables.product.prodname_vscode_shortname⟧、⟦L22:variables.copilot.github_copilot_app⟧、⟦L23:variables.copilot.copilot_cli_short⟧、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦U54⟧) ⟦I36⟧を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦L24:variables.copilot.agents_window⟧** | ⟦L25:variables.product.prodname_copilot⟧、⟦L26:variables.product.prodname_anthropic_claude_short⟧、または⟦L27:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを⟦L28:variables.product.prodname_vscode_shortname⟧内で使用し、[インターフェイス間でセッションを継続します](⟦U55⟧)。 |
| **別のマシンの⟦L29:variables.product.prodname_vscode_shortname⟧** | [SSH](⟦U56⟧)または[開発トンネル](⟦U57⟧)を通じた、⟦L30:variables.product.prodname_vscode_shortname⟧固有のリモート接続を使用します。開発トンネルは[ブラウザーベースの⟦L31:variables.copilot.agents_window⟧](⟦U58⟧)もサポートしています。 |

自分のマシンで実行されるセッションの場合、ホストを起動したままアクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、その後そのセッションを再度開いて作業を継続します。

自身のプライベートリポジトリを使用して、[⟦L32:variables.product.prodname_vscode_shortname⟧でクラウドエージェントタスクを開始し、⟦L33:variables.copilot.copilot_cli_short⟧でそれを継続します](⟦U59⟧)（実験的機能）。

ツールが実行される場所とモデルがホストされる場所は、個別の選択です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御を維持する

AIは不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに取り入れるかを決定する責任はユーザーにあります。

* **統合する前にレビューする。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認して結果を検証します](⟦U60⟧)。
* **アクションを制御し、作業をリダイレクトする。** [権限と承認](⟦U61⟧)を使用して、確認を必要とするアクションを決定します。[リクエストを誘導または停止する](⟦U62⟧)ことはできますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離について理解する。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦U63⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティベースライン](⟦U64⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](⟦U65⟧)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦U66⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](⟦U67⟧)の使用方法を参照してください。
