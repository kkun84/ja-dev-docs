# ⟦L1:variables.product.prodname_vscode_shortname⟧でのAIを活用した開発

⟦L2:variables.product.prodname_vscode⟧では、タスクのニーズに合わせて、必要なだけのAIを自由にご活用いただけます。入力時のサジェスト機能の利用、コード、テスト、デバッガーの横で動作するエージェントとの協業、あるいは⟦L3:variables.copilot.agents_window⟧でのプロジェクトを跨いだタスクの調整などを行います。作業の変化に応じて、これらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦L4:variables.product.prodname_copilot_short⟧、⟦L5:variables.product.prodname_anthropic_claude_short⟧、または⟦L6:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを利用できます。ハーネスは、モデルの周囲にツールやワークフローを提供します。カスタマイズやプラグインを利用することで、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦L7:variables.copilot.github_environments⟧を通じて自分のマシン上のセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](⟦U40⟧)は、モデルとツールを使用して関連コードの検索、変更の実行、およびチェックを行います。⟦L12:variables.copilot.chat_view⟧と⟦L13:variables.copilot.agents_window⟧の両方でエージェントが実行されます。ユーザーが目標を設定し、作業を誘導して、結果を確認します。

定型的な作業については、プロンプトを[自動化](⟦U41⟧)として保存します。スケジュールに従ってローカルで実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業のためにクラウド自動化⟦I34⟧を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

特定の編集には、コードから離れることなく[インラインチャット](⟦U42⟧)を使用します。特定のタスクの機能を比較するには、[AI機能のチートシート](⟦U43⟧)を使用します。

## モデル、エージェント、およびツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](⟦U44⟧)。ニーズの変化に応じて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦L14:variables.product.prodname_copilot⟧を通じて[複数のプロバイダーからモデルを選択する](⟦U45⟧)、または独自の[APIキー（BYOK）](⟦U46⟧)やサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](⟦U47⟧)に基づいて、⟦L15:variables.product.prodname_copilot_short⟧、⟦L16:variables.product.prodname_anthropic_claude_short⟧、または⟦L17:variables.product.prodname_openai_codex_short⟧から選択します。 |
| **アクセスと課金** | 既存の⟦L18:variables.product.prodname_copilot⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦U48⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦U49⟧)、[プロジェクトの指示](⟦U50⟧)、[スキル](⟦U51⟧)を使用してエージェントを調整します。[Model Context Protocol (MCP) サーバー](⟦U52⟧)を介して外部ツールを接続します。 |

## インターフェイスおよびマシン間の継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境をホスト側に維持したまま、エージェントと対話する場所を選択します。セッションのサポート内容や要件は、ハーネスや宛先によって異なります。

| 作業を行いたい場所 | ここから開始 |
|------------------------|------------|
| **⟦L19:variables.product.prodname_copilot_short⟧のアプリとデバイス間** | [⟦L20:variables.copilot.github_environments⟧](⟦U53⟧) ⟦I35⟧を使用して開発用マシンを登録し、⟦L21:variables.product.prodname_vscode_shortname⟧、⟦L22:variables.copilot.github_copilot_app⟧、⟦L23:variables.copilot.copilot_cli_short⟧、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦U54⟧) ⟦I36⟧を使用します。既存のクラウドセッションを再度開いて会話を続行します。実行はクラウド環境内で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦L24:variables.copilot.agents_window⟧** | ⟦L25:variables.product.prodname_copilot⟧、⟦L26:variables.product.prodname_anthropic_claude_short⟧、または⟦L27:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを⟦L28:variables.product.prodname_vscode_shortname⟧内で使用し、[インターフェイス間でセッションを継続します](⟦U55⟧)。 |
| **別マシンの⟦L29:variables.product.prodname_vscode_shortname⟧** | [SSH](⟦U56⟧)または[開発用トンネル](⟦U57⟧)を介した⟦L30:variables.product.prodname_vscode_shortname⟧固有のリモート接続を使用します。開発用トンネルは[ブラウザーベースの⟦L31:variables.copilot.agents_window⟧](⟦U58⟧)もサポートしています。 |

ご自身のマシン上で実行されるセッションの場合は、ホストを稼働状態にしてアクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、その後そのセッションを再び開いて作業を続行します。

独自プライベートリポジトリを使用して、[⟦L32:variables.product.prodname_vscode_shortname⟧でクラウドエージェントタスクを開始し、⟦L33:variables.copilot.copilot_cli_short⟧でそれを続行します](⟦U59⟧)（実験的機能）。

ツールが実行される場所と、モデルがホストされている場所は個別の選択事項です。エージェントは、ホストされたプロバイダーにモデルのリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AIは不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに反映させるかの決定については、引き続きユーザーが責任を負います。

* **統合前の確認。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。[差分を確認して結果を検証してから](⟦U60⟧)、変更をコミットまたはマージしてください。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦U61⟧)を使用して、確認を必要とするアクションを決定します。[リクエストの誘導や停止を行うことができます](⟦U62⟧)が、停止しても完了したアクションや外部サービスへの変更は取り消されません。
* **分離の理解。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムおよびネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦U63⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦U64⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](⟦U65⟧)を通じて、利用可能なエージェント、モデル、およびツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティングの手順](⟦U66⟧)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](⟦U67⟧)の使用方法を参照してください。
