## 2026年11月12日

* テキストファイル、Markdownドキュメント、チャット、統合ブラウザタブを作成するためのエディタタブバーの **+** メニューを追加します。 _[#347849: Experimental new tab (+) button in the editor tab bar](⟦5HYE⟧)_
* コードの生成、チャットの開始、言語の選択、または無題のファイルを別のエディタで再度開くためのアクションを追加します。 _[#347848: Experiment: show a list of actions in the hint of new untitled files](⟦DM8R⟧)_
* チャットに貼り付けられた画像に、可能な場合はソースファイルにちなんだ名前を付けます。 _[#347828: Chat: name pasted images after their source file](⟦XHTT⟧)_
* 兄弟プロジェクト間での移動を減らすため、Agentsウィンドウの **Open Folder** ダイアログを、選択したローカルフォルダーの親から開始します。 _[#335652: Choose Folder: Make parent folder of current folder the starting point](⟦F3M2⟧)_
* Agentsウィンドウのクリーンアップエディタでワークツリーをフィルターおよびソートするためにツールバーメニューを使用します。 _[#347138: Controls area for worktree cleanup could use some design love](⟦TA28⟧)_
* HTMLおよびCSSファイルの単行の ⟦J9WE⟧ コメントのミニマップセクションヘッダーを表示します。 _[#210637: Minimap section headers are not shown for regions in HTML and CSS](⟦BRVZ⟧)_
* [ローカル拡張機能開発](⟦PDKJ⟧)中に、エディタおよびAgentsウィンドウのタイトルバーにボタンを提供する機能を追加するための、提案中の ⟦YJ5H⟧ APIを追加します。 _[#347839: Proposed API: let extensions contribute buttons to the title bar of the editor and Agents windows](⟦MCWB⟧)_
* 実験的な **AI Usage Statistics** ステータスバーウィジェットを削除します。 _[#340001: Remove the AI Usage Statistics widget](⟦4KHK⟧)_

## 2026年11月11日

* 両方のウィンドウが同じエージェントホストを使用している場合、Agentsウィンドウと、WSL、Remote - SSH、またはDev Containerのエディタウィンドウの間でエージェントセッションを共有します。 _[#346859: Share agent host sessions between the Agents Window and WSL, SSH and Dev Container editor windows](⟦T6QG⟧)_
* 互換性のある受信トレイカテゴリ間でセッションをドラッグして、ピン留め、保持、クリア、アーカイブ、または再開します（実験的）。 _[#346934: Inbox mode: Sessions cannot be dragged between groups](⟦TSM9⟧)_
* すべてのWebリンクを統合ブラウザで開くことを有効にします。 _[#316528: Option to open all links in Integrated Browser](⟦X9SQ⟧)_

## 2026年11月10日

* 受信トレイモードの対象セッションに対して、インラインの **Merge Pull Request** アクションを追加します（実験的）。 _[#346936: Inbox mode: Ready to Merge sessions have no inline Merge action](⟦KA5S⟧)_
* 受信トレイモード（実験的）で空のカテゴリを非表示にし、**Inbox** は表示し続けます。 _[#346938: Inbox mode: Empty sections take up too much vertical space](⟦BEJD⟧)_
* Agentsウィンドウで Compare Models (Preview) の親チャットにマウスオーバーすると、その元の設定が表示されます。 _[#347109: Model compare: show original settings on hover of the parent chat](⟦HZ65⟧)_
* セッション復元のリマインダーを残したまま、ワークツリークリーンアップの確認メッセージを短縮します。 _[#347134: Worktree cleanup confirmation is unncessarily wordy](⟦JNJW⟧)_
* Markdownエディタでの折りたたみ可能な ⟦X6ZY⟧ セクションのサポートを追加します（実験的）。 _[#347433: Markdown editor: render ⟦RRGP⟧/⟦TVVQ⟧ as collapsible sections](⟦CCYQ⟧)_
* チャット入力の上部にピン留めされたチャットファイルを表示する機能を追加します（実験的）。 _[#345427: Let extensions dock views above the chat input](⟦KPP2⟧)_
* VS Codeペットを非表示にするコンテキストメニューオプションを追加します（実験的）。 _[#346510: Remove option for vscode-pet](⟦4BN2⟧)_
* 受信トレイのセッションをワークスペースおよび実行環境でフィルターします（実験的）。 _[#347488: Add workspace and environment scope pickers to Inbox](⟦T3AS⟧)_
