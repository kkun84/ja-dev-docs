## はじめに

⟦VB25⟧上のさまざまな場所から ⟦SK43⟧ セッションを開始できます。セッションの実行後は、ブラウザから離れることなく、その進行状況を監視したり、フォローアッププロンプトで指示を与えたり、結果として作成されたpull requestに対して反復的な作業を行ったりすることができます。

⟦PPTR⟧ の詳細については、[AUTOTITLE](⟦M4FJ⟧) を参照してください。

また、これらの同じエントリーポイントから ⟦7TCN⟧ を使用して、パートナーが構築したエージェントを開始することもできます。詳細については、[AUTOTITLE](⟦9K7X⟧) を参照してください。

## ⟦TVGY⟧ セッションの開始

* [github.com/copilot](⟦RESR⟧) にある ⟦HGSN⟧ ⟦4MAH⟧ のホームページ

* リポジトリ内の **⟦ZSX9⟧ Agents** タブまたはパネル

デフォルト設定のままプロンプトをすぐに送信することも、プロンプトを送信する前にタスクに合わせてセッションを設定することもできます。

1. プロンプトボックスに、⟦X3ZD⟧ に実行させたい内容を入力します。望む結果や制約事項を含めてください。

   > [!TIP]
   > プロンプト内でスラッシュコマンドを使用して、第2の意見を求めるための ⟦9D3Y⟧、脆弱性のリポジトリレビューを行うための ⟦GJP5⟧、セッションの使用状況情報を表示するための ⟦E7BR⟧ などの特定のアクションを実行することもできます。

1. オプションで、**⟦Q9WW⟧ Attach** をクリックして、⟦FJF7⟧ にリクエストの参照情報を提供します。

   **Files and folders**、**Upload from computer**、**Repository**、または **Space** を選択して、リクエストのコンテキストを提供します。

   クラウドサンドボックスセッションの場合、コネクタやパーソナルカスタム MCP サーバーを設定することで、サードパーティソースから追加のコンテキストを提供できます。[AUTOTITLE](⟦J423⟧) および [AUTOTITLE](⟦CGKJ⟧) を参照してください。

1. **Mode** ピッカーを開いて、⟦JCYQ⟧ とどのように連携するかを選択します。

   * **Interactive**: （デフォルト）⟦5KR8⟧ と段階的に作業を進めます。
   * **Autopilot**: タスクを ⟦NYJX⟧ に委任して、エンドツーエンドで実行させます。

   * **Always ask** を選択すると、リクエストごとに承認が必要になります。
   * **Allow all** を選択すると、すべてのツール、パス、および URL リクエストが自動的に承認されます。

1. **Models** ピッカーを開き、**Auto** （デフォルト）または特定のモデルを選択します。モデルは、速度とコスト効率、汎用性と知能、または複雑なタスクへの適性のいずれかを選択できるように、その長所ごとにグループ化されています。選択したモデルが **Balance** などの設定可能な推論をサポートしている場合、ドロップダウンメニューを使用して推論レベルを選択することもできます。

1. プロンプトボックスの下部にある **Chat** セッションコンテキストピッカーを使用して、セッションのスコープ（個人、組織、またはリポジトリ）を選択します。

   * 検索ボックスにリポジトリ名を入力して、追加するリポジトリを検索します。
   * **Ask anything across repositories** の下にある **Chat** を選択すると、複数のリポジトリにまたがって質問できます。デフォルトのスコープは個人のリポジトリです。右側の画像をクリックしてアカウントメニューを開き、組織を選択するか、リポジトリの所有者（ユーザーまたは組織）で検索してスコープを変更します。
   * **Work in a repository** の下で、作業を行う最近のリポジトリを選択します。リストされるリポジトリは、選択したスコープを反映しています。

   > [!NOTE]
   > * **Attach** メニュー（前のステップ）からリポジトリを追加すると、プロンプトの参照情報（コンテキスト素材）が提供されます。一方、ここで **Start a session** の下でリポジトリを選択すると、そのリポジトリがセッションの作業用リポジトリ（スコープ）になります。セッションの開始時に、クラウドサンドボックスはそのリポジトリのコピーを作成し、既存の制約内でそのコンテンツを操作する権限を ⟦4NAJ⟧ に与えます。
   > * リポジトリがリストに表示されない場合、個人の設定、組織、またはエンタープライズのポリシーによって ⟦V4VB⟧ から除外されている可能性があります。

   オプションで、上記のリポジトリを選択した場合、**main** （または表示されているデフォルトブランチ名）をクリックして、⟦FBW9⟧ が作業コンテキストとして使用し、その中で操作するブランチを選択することもできます。

⟦RPNB⟧

1. **Send message** をクリックするか、<kbd>Enter</kbd> キーを押してプロンプトを送信し、セッションを開始します。

⟦8D7A⟧ はプロンプトに応答し、選択したコンテキストと環境に基づいてセッションを開始します。要求された場合、⟦DG8B⟧ は変更されたファイルのリスト、pull request、生成された成果物（リサーチプランなど）、およびその他の関連する出力を生成します。

## pull request での作業の継続

### ⟦8K9S⟧ への変更の依頼

⟦EDHP⟧ のウェブインターフェースから pull request のコメント（レビューやレビューコメントではない）を送信する際は、モデルピッカーでモデルを選択します。⟦4RAQ⟧ はデフォルトで元の pull request のモデルを使用します。
