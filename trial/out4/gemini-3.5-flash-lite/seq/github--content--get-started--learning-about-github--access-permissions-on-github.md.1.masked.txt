## ⟦L1:variables.product.github⟧上のアクセス権限について

⟦L2:reusables.organizations.about-roles⟧

ロールの動作はアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦U11⟧)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_という2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦U12⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_オーナー_⟦L3⟧、_請求管理者_⟦L4⟧、または_メンバー_のロールを設定できます。オーナーは組織に対する完全な管理者アクセス権を持ち、請求管理者は請求設定を管理できます⟦L6⟧。オーナー⟦L5⟧メンバーは、その他の全員に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦U13⟧)
* [AUTOTITLE](⟦U14⟧)
* [AUTOTITLE](⟦U15⟧)

## 企業アカウント

企業アカウントには、企業設定へのユーザーのアクセスを定義する事前定義されたロールが複数用意されています。また、カスタム企業ロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、⟦L7⟧⟦L8:variables.product.prodname_ghe_cloud⟧ドキュメントの[AUTOTITLE](⟦U16⟧)⟦L9⟧[AUTOTITLE](⟦U17⟧)⟦L10⟧を参照してください。
