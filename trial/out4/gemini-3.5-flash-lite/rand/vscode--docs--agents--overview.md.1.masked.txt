# ⟦9PSS⟧でのAIによるビルド

⟦GH8K⟧では、タスクに必要な量のAIを自由に使用できます。入力に応じたサジェストの取得、コード・テスト・デバッガーの横で動作するエージェントとの協業、あるいは⟦D5RA⟧での複数プロジェクトにわたるタスクの調整を行います。作業の変化に合わせて、これらのアプローチを組み合わせてください。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦XZRD⟧、⟦4F22⟧、または⟦E7W3⟧のエージェントハーネスで作業します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦DYCR⟧を通じて自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](⟦42YZ⟧)は、モデルとツールを使用して関連コードの検索、変更の適用、チェックの実行を行います。⟦V5DD⟧と⟦SZKK⟧の両方がエージェントを実行します。あなたが目標を設定し、作業を誘導し、結果を確認します。

日常的な作業には、プロンプトを[自動化](⟦Z49M⟧)として保存します。スケジュールに従ってローカルで実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業にクラウド自動化⟦T575⟧を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

特定の編集を行うには、コードから離れることなく[インラインチャット](⟦RYG2⟧)を使用します。特定のタスクの機能を比較するには、[AI機能の早見表](⟦TBCE⟧)を使用します。

## モデル、エージェント、およびツールを選択する

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](⟦EFRB⟧)。ニーズの変化に応じて、以下の選択肢を調整できます。

| 選択項目 | オプション |
|--------|---------|
| **モデル** | ⟦VZVN⟧経由で[複数のプロバイダーのモデル](⟦EC2P⟧)を選択するか、独自の[APIキー（BYOK）](⟦DPSY⟧)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](⟦SX43⟧)に基づいて、⟦65BQ⟧、⟦7JVE⟧、または⟦HMYB⟧から選択します。 |
| **アクセスと課金** | 既存の⟦P9XA⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦Z8TC⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦VW8W⟧)、[プロジェクト指示](⟦WZPZ⟧)、および[スキル](⟦97CZ⟧)を使用してエージェントを調整します。[Model Context Protocol（MCP）サーバー](⟦H7YT⟧)を介して外部ツールを接続します。 |

## インターフェイスとマシンの間で継続する

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシンの間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境がホストに残ったまま、エージェントとやり取りする場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦TSN7⟧のアプリやデバイス間** | [⟦J429⟧](⟦R5Q7⟧) ⟦CC9N⟧を使用して開発用マシンを登録し、⟦V2XD⟧、⟦ZXWE⟧、⟦5AB7⟧、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **マネージドクラウドコンピュート上** | 自分のマシンをオンラインに維持しなくてもインタラクティブなエージェント作業を行える[クラウドセッション](⟦WG4J⟧) ⟦SQZS⟧を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境内で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦HT2B⟧** | ⟦D524⟧で⟦BYAW⟧、⟦7XK2⟧、または⟦9FWR⟧エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](⟦VDBP⟧)。 |
| **別のマシンの⟦7Y62⟧** | [SSH](⟦XQBS⟧)または[開発トンネル](⟦Q7R5⟧)を介して、⟦Y32D⟧固有のリモート接続を使用します。開発トンネルは[ブラウザーベースの⟦BNKT⟧](⟦CKPF⟧)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを稼働状態にしてアクセス可能な状態に維持してください。クラウドセッションでは、代わりにマネージドコンピュートを使用します。クラウドでの作業用にクラウドセッションを開始し、後からそのセッションを再度開いて継続します。

独自 プライベートリポジトリを使用して、[⟦8QGQ⟧でクラウドエージェントタスクを開始し、⟦6ZA6⟧で継続します](⟦EYWP⟧)（実験的機能）。

ツールが実行される場所とモデルがホストされる場所は、個別の選択項目です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御を維持する

AIは不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに取り入れるかの判断責任は常にあなたが負います。

* **統合する前に確認する。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認し、結果を検証します](⟦4MK8⟧)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦CBV8⟧)を使用して、どのアクションに確認が必要かを決定します。[リクエストの誘導や停止を行うことができます](⟦2VKY⟧)が、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の仕組みを理解する。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦SDDK⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦SZBP⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](⟦4W9Y⟧)を通じて、利用可能なエージェント、モデル、およびツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦VSTJ⟧)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](⟦N6ZT⟧)の使用方法を参照してください。
