## はじめに

⟦L1:variables.copilot.copilot_in_the_cloud⟧セッションは、⟦L2:variables.product.github⟧上の複数の場所から開始できます。セッションの実行中は、ブラウザーを離れることなく、進捗状況の監視、フォローアッププロンプトによる指示、結果のpull requestの反復作業を行えます。

⟦L3:variables.copilot.copilot_in_the_cloud_short⟧について詳しくは、[AUTOTITLE](⟦U142⟧)を参照してください。

⟦L4:variables.copilot.agent_apps⟧を使用して、これらと同じエントリポイントからパートナーが構築したエージェントを開始することもできます。詳細については、[AUTOTITLE](⟦U143⟧)を参照してください。
