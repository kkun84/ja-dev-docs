## GitHubのアクセス権限について

⟦CFFA⟧

ロールの仕組みは、アカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦VNCN⟧)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_という2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦JSHK⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_owner_⟦CQAD⟧、_billing manager_⟦J2EZ⟧、または_member_のロールを設定できます。オーナーは組織に対する完全な管理者アクセス権を持ち⟦7KC9⟧、請求マネージャーは請求設定を管理できます⟦QVHY⟧。メンバーは、それ以外のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦8Y9B⟧)
* [AUTOTITLE](⟦K43A⟧)
* [AUTOTITLE](⟦WBNY⟧)

## 企業アカウント

企業アカウントには、Enterpriseの設定へのユーザーのアクセスを定義する、事前に定義されたさまざまなロールがあります。独自の細かな権限セットを定義するためのカスタムEnterpriseロールを作成することもできます。

詳細については、GitHub Enterprise Cloudドキュメントの⟦SKCS⟧[AUTOTITLE](⟦HPMW⟧)⟦S9YR⟧[AUTOTITLE](⟦XPKA⟧)⟦MVBR⟧を参照してください。
