## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリ所有者_ と _collaborators_ という2つの権限レベルがあります。詳細については、[AUTOTITLE](/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository) を参照してください。

## 組織アカウント

組織のメンバーには、_owner_⟦FA8Y⟧、_billing manager_⟦C8F4⟧、または _member_ のロールを設定できます。所有者は組織への完全な管理アクセス権を持ち⟦95NJ⟧、請求マネージャーは請求設定を管理できます⟦WP6Q⟧。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization)
* [AUTOTITLE](/organizations/managing-user-access-to-your-organizations-repositories/managing-repository-roles/repository-roles-for-an-organization)
* [AUTOTITLE](/organizations/organizing-members-into-teams/about-teams)

## Enterprise アカウント

Enterprise アカウントには、Enterprise の設定へのユーザーのアクセスを定義する事前定義されたロールがさまざまあります。また、カスタム Enterprise ロールを作成して、独自の細かい権限のセットを定義することもできます。

詳細については、⟦28AS⟧⟦RB8J⟧ ドキュメントの [AUTOTITLE](/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦NKKG⟧[AUTOTITLE](/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦GBXA⟧ を参照してください。
