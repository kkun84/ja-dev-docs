## はじめに

⟦L1:variables.copilot.copilot_in_the_cloud⟧セッションは、⟦L2:variables.product.github⟧上のいくつかの場所から開始できます。セッションの実行中は、ブラウザを離れることなく、進捗状況のモニタリング、フォローアッププロンプトによる指示、結果のpull requestに対する調整を行うことができます。

⟦L3:variables.copilot.copilot_in_the_cloud_short⟧について詳しくは、[AUTOTITLE](⟦U142⟧)をご覧ください。

また、⟦L4:variables.copilot.agent_apps⟧を使用して、同じエントリポイントからパートナーが構築したエージェントを開始することもできます。詳しくは、[AUTOTITLE](⟦U143⟧)をご覧ください。
