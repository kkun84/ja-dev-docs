# ⟦C5G3⟧ で AI を活用したビルド

⟦7PJS⟧ でタスクに必要なだけの AI を活用できます。入力に応じたサジェストの取得、コード、テスト、デバッガーの横でエージェントとの共同作業、または ⟦6Z4N⟧ でのプロジェクトをまたいだタスクの調整を行います。作業の変化に合わせて、これらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自の API キーを使用して、⟦2K2S⟧、⟦527R⟧、または ⟦ESMG⟧ のエージェントハーネスを使用します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

Continuity 機能を使用すると、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦RJ5S⟧ を使用して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](⟦SGAG⟧)はモデルとツールを使用して、関連するコードの検索、変更の実行、チェックの実行を行います。⟦GVAS⟧ と ⟦FGDS⟧ の両方がエージェントを実行します。あなたが目標を設定し、作業を誘導し、結果を確認します。

ルーチンワークの場合は、プロンプトを[自動化](⟦9AVN⟧)として保存します。ローカルでスケジュール実行するか、コンピューターの電源がオフのときでも継続するスケジュールまたはイベントトリガーによるリポジトリ作業のために、クラウド自動化 ⟦8WEZ⟧ を使用します。定期的な作業を有効にする前に、手動実行を確認します。

集中的な編集を行うには、コードから離れることなく[インラインチャット](⟦W2VA⟧)を使用します。特定のタスクの機能を比較するには、[AI 機能の早見表](⟦68XC⟧)を使用します。

## モデル、エージェント、およびツールを選択する

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](⟦84Q6⟧)。ニーズの変化に合わせて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦VSJN⟧ を通じて[複数のプロバイダーのモデル](⟦BJNN⟧)を選択するか、独自の[API キー (BYOK)](⟦WME6⟧) またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](⟦FWPQ⟧)に基づいて、⟦V9BH⟧、⟦FWW7⟧、または ⟦68B3⟧ から選択します。 |
| **アクセスと課金** | 既存の ⟦P7AQ⟧ プラン、サポートされているプロバイダーアカウント、または API キーを使用します。[ハーネスの要件](⟦GSNC⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦CQ2F⟧)、[プロジェクト指示](⟦SM43⟧)、[スキル](⟦A2RN⟧)を使用してエージェントを調整します。[Model Context Protocol (MCP) サーバー](⟦SF5R⟧)を通じて外部ツールを接続します。 |

## インターフェイスとマシン間で継続する

Continuity とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行がホストに残ったまま、エージェントと対話する場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦3H7W⟧ アプリとデバイス間** | [⟦9VZT⟧](⟦RD44⟧) ⟦8TC4⟧ を使用して開発マシンを登録し、⟦VTWR⟧、⟦QQVN⟧、⟦YQVX⟧、GitHub.com、または GitHub Mobile からエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持することなくインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦SD54⟧) ⟦H4TF⟧ を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは ⟦8EVX⟧** | ⟦924Y⟧ で ⟦SA6X⟧、⟦BTEX⟧、または ⟦9Z5J⟧ エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](⟦AS8D⟧)。 |
| **別のマシンの ⟦AC9V⟧** | [SSH](⟦9YNY⟧) または[開発トンネル](⟦JX48⟧)を通じた ⟦4KQ4⟧ 固有のリモート接続を使用します。開発トンネルは[ブラウザーベースの ⟦ZBGC⟧](⟦8KFJ⟧)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを実行可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートを使用します。クラウドでの作業用にクラウドセッションを開始し、後でそのセッションを再度開いて継続します。

独自 プライベートリポジトリを使用して、[⟦CM84⟧ でクラウドエージェントタスクを開始し、⟦9D7P⟧ で継続します](⟦G93X⟧) (実験的)。

ツールが実行される場所とモデルがホストされる場所は、個別の選択です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御を維持する

AI は誤ったコードを生成したり、意図を誤解したりする可能性があります。コードベースにどのような変更が取り込まれるかを決定する責任は、常にあなたが負います。

* **統合する前にレビューする。** エージェントはセッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認して結果を検証します](⟦QTSM⟧)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦4PMB⟧)を使用して、確認が必要なアクションを決定します。[リクエストの誘導や停止を行うことができますが](⟦NS8X⟧)、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Git ワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦QSRP⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦BD7C⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズ AI ポリシー](⟦RZA2⟧)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦YZK2⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](⟦8X4C⟧)の使用方法を確認してください。
