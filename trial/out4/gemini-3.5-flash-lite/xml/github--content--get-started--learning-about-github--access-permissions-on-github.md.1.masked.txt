## <x id="4ADM"/> のアクセス権限について

<x id="7D54"/>

ロールの動作はアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](<x id="HWY3"/>)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_の2つの権限レベルがあります。詳細については、[AUTOTITLE](<x id="MD3J"/>)を参照してください。

## 組織アカウント

組織のメンバーには、_オーナー_<x id="F9S4"/>、_請求マネージャー_<x id="F7B5"/>、または_メンバー_のロールを割り当てることができます。オーナーは組織に対する完全な管理者アクセス権を持ち<x id="4A6C"/>、請求マネージャーは請求設定を管理できます<x id="35KB"/>。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](<x id="2GE8"/>)
* [AUTOTITLE](<x id="5D9C"/>)
* [AUTOTITLE](<x id="YHZ9"/>)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセスを定義するさまざまな事前定義済みロールがあります。また、カスタムのエンタープライズロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、<x id="96EY"/>[AUTOTITLE](<x id="6CMM"/>) (<x id="BG3W"/> ドキュメント<x id="HHGW"/>[AUTOTITLE](<x id="9Y2D"/>)<x id="6T85"/>) を参照してください。
