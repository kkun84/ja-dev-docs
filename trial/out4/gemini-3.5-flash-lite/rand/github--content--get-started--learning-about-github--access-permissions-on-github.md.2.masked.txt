## ⟦CFFA⟧ のアクセス権限について

⟦CQAD⟧

ロールの仕組みは、アカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦8Y9B⟧)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_ と _コラボレーター_ という2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦K43A⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_owner_⟦J2EZ⟧、_billing manager_、⟦7KC9⟧ または _member_ のロールを設定できます。オーナーは組織に対する完全な管理者アクセス権を持ち⟦QVHY⟧、請求マネージャーは請求設定を管理できます⟦SKCS⟧。メンバーは、その他のすべての人に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦WBNY⟧)
* [AUTOTITLE](⟦HPMW⟧)
* [AUTOTITLE](⟦XPKA⟧)

## 企業アカウント

企業アカウントには、ユーザーの企業設定へのアクセスを定義するさまざまな事前定義済みロールがあります。また、独自の細かな権限セットを定義するカスタム企業ロールを作成することもできます。

詳細については、⟦MVBR⟧ドキュメント⟦VNCN⟧の ⟦S9YR⟧[AUTOTITLE](⟦H345⟧) [AUTOTITLE](⟦7QPD⟧)⟦JSHK⟧ を参照してください。
