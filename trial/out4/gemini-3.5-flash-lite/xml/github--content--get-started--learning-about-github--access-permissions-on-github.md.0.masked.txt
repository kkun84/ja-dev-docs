## <x id="A3D2"/> のアクセス権限について

<x id="CE5R"/>

アカウントの種類によって、ロールの動作は異なります。アカウントの詳細については、[AUTOTITLE](<x id="7WWR"/>)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、**リポジトリ所有者**と**コラボレーター**という2つの権限レベルがあります。詳細については、[AUTOTITLE](<x id="AQXG"/>)を参照してください。

## 組織アカウント

組織のメンバーには、_owner_<x id="FA8Y"/>、_billing manager_<x id="C8F4"/>、または _member_ のロールを割り当てることができます。所有者は組織に対する完全な管理者アクセス権を持ち<x id="95NJ"/>、請求マネージャーは請求設定を管理できます<x id="WP6Q"/>。その他のユーザーには、デフォルトのロールとして member が割り当てられます。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](<x id="XDFS"/>)
* [AUTOTITLE](<x id="9PQX"/>)
* [AUTOTITLE](<x id="WCMJ"/>)

## 企業アカウント

企業アカウントには、Enterpriseの設定へのユーザーのアクセスを定義するさまざまな事前定義ロールがあります。また、独自の細かな権限セットを定義するために、カスタムEnterpriseロールを作成することもできます。

詳細については、<x id="RB8J"/> ドキュメント<x id="NKKG"/> の <x id="28AS"/>[AUTOTITLE](<x id="EM8V"/>)<x id="FV6S"/><x id="GBXA"/> を参照してください。
