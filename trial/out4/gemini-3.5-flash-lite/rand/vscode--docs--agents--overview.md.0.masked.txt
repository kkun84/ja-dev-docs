# ⟦2Z8X⟧でのAI活用

⟦TBAS⟧では、タスクに必要な量のAIを自由に使用できます。入力に応じたサジェストの取得、コード、テスト、デバッガーの横でのエージェントとの連携、または⟦N7PS⟧でのプロジェクトをまたいだタスクの調整を行います。作業の変化に応じて、これらのアプローチを組み合わせます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦EE2E⟧、⟦Q9EY⟧、または⟦J9K4⟧のエージェントハーネスで作業します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性機能により、やり直すことなく、サポートされているインターフェース間でエージェントの作業を引き継ぐことができます。⟦P6RN⟧を介して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](⟦T33Z⟧)は、モデルとツールを使用して関連コードの検索、変更の適用、チェックの実行を行います。⟦RBSC⟧と⟦V36Y⟧の両方でエージェントが実行されます。ユーザーは目標の設定、作業の誘導、結果の確認を行います。

定型作業の場合は、プロンプトを[自動化](⟦WKPQ⟧)として保存します。スケジュールに従ってローカルで実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリの作業にクラウド自動化⟦EK78⟧を使用します。定期的な作業を有効にする前に手動実行を確認します。

集中的な編集を行うには、コードから離れることなく[インラインチャット](⟦D729⟧)を使用します。特定のタスクの機能を比較するには、[AI機能チートシート](⟦6MSG⟧)を使用します。

## モデル、エージェント、ツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](⟦5YED⟧)。ニーズの変化に合わせて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦SJ8D⟧を介して[複数のプロバイダーのモデル](⟦2K9G⟧)を選択するか、独自の[APIキー（BYOK）](⟦2G7W⟧)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | その[ツールとワークフロー](⟦F8PY⟧)に基づいて、⟦WQGR⟧、⟦ZTF2⟧、または⟦PZQK⟧から選択します。 |
| **アクセスと課金** | 既存の⟦KASS⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦3VFZ⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦ZAHM⟧)、[プロジェクトの手順](⟦KN9D⟧)、[スキル](⟦RXR4⟧)を使用してエージェントを調整します。[Model Context Protocol（MCP）サーバー](⟦EFVG⟧)を介して外部ツールを接続します。 |

## インターフェースやマシンをまたいだ継続

継続性とは、やり直すことなく、サポートされているインターフェースやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行はホスト上に維持したまま、エージェントとやり取りする場所を選択します。セッションのサポート内容と要件は、ハーネスや宛先によって異なります。

| 作業を行いたい場所 | ここから開始 |
|------------------------|------------|
| **⟦S6YZ⟧アプリやデバイスをまたいで** | [⟦BB94⟧](⟦PVXA⟧) ⟦CGBS⟧を使用して開発マシンを登録し、⟦WTZ3⟧、⟦W6PC⟧、⟦WTQR⟧、GitHub.com、またはGitHub Mobileからそのエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上で** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦DGYQ⟧) ⟦RN2H⟧を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境内で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦CEHN⟧** | ⟦6GHF⟧で⟦YPJK⟧、⟦JFFJ⟧、または⟦SE3P⟧のエージェントハーネスを使用し、[インターフェース間でセッションを継続します](⟦J2E3⟧)。 |
| **別のマシンの⟦93HE⟧** | [SSH](⟦Z3KM⟧)または[開発用トンネル](⟦9BA3⟧)を介した⟦94S9⟧固有のリモート接続を使用します。開発用トンネルは[ブラウザベースの⟦S8BZ⟧](⟦N5SB⟧)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを稼働状態かつアクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、後でそのセッションを再度開いて継続します。

自分のプライベートリポジトリを使用して、[⟦F454⟧でクラウドエージェントタスクを開始し、⟦BSP3⟧で継続します](⟦VZHH⟧)（実験的機能）。

ツールが実行される場所とモデルがホストされる場所は個別の選択事項です。エージェントは、ホストされたプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AIは不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに反映させるかの最終決定責任は常にユーザーにあります。

* **統合前の確認。** エージェントは編集内容をセッションフォルダーやワークツリーに直接保存できます。変更をコミットまたはマージする前に、[差分を確認し、結果を検証します](⟦SM5W⟧)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦FWCJ⟧)を使用して、確認が必要なアクションを決定します。[リクエストの誘導や停止を行うことができます](⟦P6F9⟧)が、停止しても完了したアクションや外部サービスへの変更は取り消されません。
* **分離の理解。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦4VYH⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦HZ7E⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](⟦BWHV⟧)を通じて利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦3BPX⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のユーザー補助機能](⟦HG5N⟧)の使用方法を確認してください。
