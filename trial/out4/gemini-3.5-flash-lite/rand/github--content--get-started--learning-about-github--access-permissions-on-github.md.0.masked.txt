## ⟦A3D2⟧ のアクセス権限について

⟦CE5R⟧

ロールの動作はアカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦7WWR⟧) をご覧ください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_ と _コラボレーター_ の2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦AQXG⟧) をご覧ください。

## 組織アカウント

組織のメンバーには、_owner_⟦FA8Y⟧、_billing manager_⟦C8F4⟧、または _member_ のロールを設定できます。オーナーは組織に対する完全な管理アクセス権を持ち⟦95NJ⟧、請求マネージャーは請求設定を管理できます⟦WP6Q⟧。その他のメンバーにはデフォルトで member ロールが割り当てられます。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下をご覧ください。
* [AUTOTITLE](⟦XDFS⟧)
* [AUTOTITLE](⟦9PQX⟧)
* [AUTOTITLE](⟦WCMJ⟧)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセスを定義する事前定義された一連のロールがあります。また、独自のきめ細かなアクセス許可のセットを定義するカスタムエンタープライズロールを作成することもできます。

詳細については、⟦28AS⟧⟦RB8J⟧ ドキュメントの [AUTOTITLE](⟦EM8V⟧)⟦NKKG⟧[AUTOTITLE](⟦FV6S⟧)⟦GBXA⟧ をご覧ください。
