# Build with AI in VS Code

Visual Studio Code では、タスクに必要なだけ AI を活用できます。入力に応じたサジェストの取得、コード、テスト、デバッガーの横でのエージェントとの共同作業、Agents ウィンドウでのプロジェクトを跨いだタスクの調整などを行います。作業の変化に合わせて、これらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自の API キーを使用して、Copilot、Claude、または Codex のエージェントハーネスで作業します。ハーネスは、モデルの周囲にあるツールやワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

Continuity 機能を使用すると、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。GitHub environments を介して自分のマシンのセッションに接続するか、ローカルのホストをオンラインに保たずにクラウドセッションを使用します。

[エージェント](⟦DYCR⟧)は、モデルとツールを使用して関連するコードを見つけ、変更を加え、チェックを実行します。Chat ビューと Agents ウィンドウの両方でエージェントが実行されます。目標を設定し、作業を誘導し、結果をレビューします。

ルーチンワークの場合は、プロンプトを[自動化](⟦YE6D⟧)として保存します。ローカルでスケジュールに従って実行するか、クラウド自動化 ⟦9PSS⟧ を使用して、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業を実行します。定期的な作業を有効にする前に、手動実行をレビューしてください。

焦点を絞った編集を行うには、コードから離れることなく[インラインチャット](⟦3X9M⟧)を使用します。特定のタスクの機能を比較するには、[AI 機能チートシート](⟦85D8⟧)を使用します。

## モデル、エージェント、およびツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](⟦N9H4⟧)。ニーズの変化に合わせて、以下の選択肢を調整できます。

| 選択 | オプション |
|--------|---------|
| **Models** | GitHub Copilot を通じて[複数のプロバイダーのモデルを選択するか](⟦V5DD⟧)、独自の[API キー (BYOK)](⟦SZKK⟧) またはサポートされているローカルモデルを使用します。 |
| **Agent harnesses** | [ツールとワークフロー](⟦VZVN⟧)に基づいて、Copilot、Claude、または Codex から選択します。 |
| **Access and billing** | 既存の GitHub Copilot プラン、サポートされているプロバイダーのアカウント、または API キーを使用します。[ハーネスの要件](⟦65BQ⟧)を確認してください。 |
| **Customization** | [プラグイン](⟦7JVE⟧)、[プロジェクトの手順](⟦HMYB⟧)、[スキル](⟦P9XA⟧)を使用してエージェントを調整します。[Model Context Protocol (MCP) サーバー](⟦TSN7⟧)を介して外部ツールを接続します。 |

## インターフェイスとマシンを跨いだ継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシンを跨いでエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境はホストに残したまま、エージェントと対話する場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業を行いたい場所 | ここから開始 |
|------------------------|------------|
| **Copilot アプリとデバイスを跨ぐ** | [GitHub environments](⟦J429⟧) ⟦GH8K⟧ を使用して開発マシンを登録し、VS Code、GitHub Copilot アプリ、Copilot CLI、GitHub.com、または GitHub Mobile からエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンの電源をオンラインに保つことなく対話型のエージェント作業を行うには、[クラウドセッション](⟦V2XD⟧) ⟦D5RA⟧ を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは Agents ウィンドウ** | VS Code で GitHub Copilot、Claude、または Codex エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](⟦ZXWE⟧)。 |
| **別のマシンの VS Code** | [SSH](⟦5AB7⟧) または[dev tunnel](⟦HT2B⟧) を介した VS Code 固有のリモート接続を使用します。Dev tunnel は[ブラウザーベースの Agents ウィンドウ](⟦BYAW⟧)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを実行可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートを使用します。クラウドでの作業のためにクラウドセッションを開始し、後からそのセッションを再度開いて継続します。

独自のプライベートリポジトリを使用して、[VS Code でクラウドエージェントタスクを開始し、Copilot CLI で継続します](⟦7XK2⟧) (実験的機能)。

ツールが実行される場所とモデルがホストされる場所は、個別の選択です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AI は誤ったコードを生成したり、意図を誤解したりする場合があります。どの変更をコードベースに取り入れるかの最終的な責任はユーザーが負います。

* **統合前のレビュー。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[diff をレビューして結果を検証します](⟦9FWR⟧)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦D524⟧)を使用して、どのアクションに確認が必要かを決定します。[リクエストを誘導または停止する](⟦7Y62⟧)ことができますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Git ワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドのファイルシステムおよびネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦Y32D⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦BNKT⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズ AI ポリシー](⟦8QGQ⟧)を通じて、利用可能なエージェント、モデル、およびツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦6ZA6⟧)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のユーザー補助機能](⟦T575⟧)の使用方法を参照してください。
