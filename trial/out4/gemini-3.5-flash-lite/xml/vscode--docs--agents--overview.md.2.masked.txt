# Build with AI in <x id="C5G3"/>

<x id="7PJS"/> でタスクに必要なだけ、または必要な範囲でAIを活用します。入力に応じたサジェストを受け取る、コード、テスト、デバッガーの横でエージェントと協働する、あるいは <x id="6Z4N"/> でプロジェクト横断的にタスクを調整します。作業の変化に合わせてこれらのアプローチを組み合わせます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは自身のAPIキーを使用して、<x id="2K2S"/>、<x id="527R"/>、または <x id="ESMG"/> エージェントハーネスで作業します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

Continuity（継続性）機能を使用すると、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。自分のマシンのセッションに <x id="RJ5S"/> 経由で接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](<x id="SGAG"/>)は、モデルとツールを使用して関連コードを見つけ、変更を加え、チェックを実行します。<x id="GVAS"/> と <x id="FGDS"/> の両方でエージェントが実行されます。ユーザーは目標を設定し、作業を誘導し、結果を確認します。

定型作業の場合は、プロンプトを[自動化](<x id="9AVN"/>)として保存します。スケジュールに従ってローカルで実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業のためにクラウド自動化 <x id="8WEZ"/> を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

特定の編集には、コードから離れることなく[インラインチャット](<x id="W2VA"/>)を使用します。特定のタスクの機能を比較するには、[AI機能早見表](<x id="68XC"/>)を使用します。

## モデル、エージェント、およびツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](<x id="84Q6"/>)。ニーズの変化に応じて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **Models** | <x id="VSJN"/> を通じて[複数のプロバイダーのモデル](<x id="BJNN"/>)を選択するか、独自の[APIキー (BYOK)](<x id="WME6"/>) またはサポートされているローカルモデルを使用します。 |
| **Agent harnesses** | [ツールとワークフロー](<x id="FWPQ"/>)に基づいて、<x id="V9BH"/>、<x id="FWW7"/>、または <x id="68B3"/> から選択します。 |
| **Access and billing** | 既存の <x id="P7AQ"/> プラン、サポートされているプロバイダーのアカウント、またはAPIキーを使用します。[ハーネスの要件](<x id="GSNC"/>)を確認してください。 |
| **Customization** | [プラグイン](<x id="CQ2F"/>)、[プロジェクト指示](<x id="SM43"/>)、[スキル](<x id="A2RN"/>)でエージェントをカスタマイズします。[Model Context Protocol (MCP) サーバー](<x id="SF5R"/>)を通じて外部ツールを接続します。 |

## インターフェイスとマシンの間での継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行はホストに残したまま、エージェントとやり取りする場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業環境 | ここから開始 |
|------------------------|------------|
| **<x id="3H7W"/> アプリとデバイス間** | [<x id="9VZT"/>](<x id="RD44"/>) <x id="8TC4"/> を使用して開発マシンを登録し、<x id="VTWR"/>、<x id="QQVN"/>、<x id="YQVX"/>、GitHub.com、または GitHub Mobile からエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](<x id="SD54"/>) <x id="H4TF"/> を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは <x id="8EVX"/>** | <x id="924Y"/> で <x id="SA6X"/>、<x id="BTEX"/>、または <x id="9Z5J"/> エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](<x id="AS8D"/>)。 |
| **別のマシンの <x id="AC9V"/>** | [SSH](<x id="9YNY"/>) または[開発用トンネル](<x id="JX48"/>)を介した <x id="4KQ4"/> 固有のリモート接続を使用します。開発用トンネルは、[ブラウザベースの <x id="ZBGC"/>](<x id="8KFJ"/>) もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを実行し、アクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業のためにクラウドセッションを開始し、後からそのセッションを再度開いて継続します。

独自のプライベートリポジトリを使用して、[<x id="CM84"/> でクラウドエージェントタスクを開始し、<x id="9D7P"/> でそれを継続します](<x id="G93X"/>) (実験的)。

ツールが実行される場所とモデルがホストされる場所は、個別の選択肢です。エージェントは、モデルリクエストをホストされたプロバイダーに送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AIは、不正確なコード生成や意図の誤解を招く可能性があります。どの変更をコードベースに取り入れるかを決定する責任はユーザーにあります。

* **統合前の確認。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認し、結果を検証します](<x id="QTSM"/>)。
* **アクションの制御と作業の誘導。** [権限と承認](<x id="4PMB"/>)を使用して、確認が必要なアクションを決定します。[リクエストの誘導や停止](<x id="NS8X"/>)を行うことができますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](<x id="QSRP"/>)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](<x id="BD7C"/>)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](<x id="RZA2"/>)を通じて、利用可能なエージェント、モデル、およびツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](<x id="YZK2"/>)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン向けのワークフローについては、[アクセシビリティビューおよびその他のアクセシビリティ機能](<x id="8X4C"/>)の使用方法を確認してください。
