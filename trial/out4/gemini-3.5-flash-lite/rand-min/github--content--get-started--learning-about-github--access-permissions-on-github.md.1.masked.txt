## ⟦4ADM⟧でのアクセス権限について

⟦7D54⟧

ロールはアカウントの種類によって動作が異なります。アカウントの詳細については、[AUTOTITLE](/get-started/learning-about-github/types-of-github-accounts)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_の2つの権限レベルがあります。詳細については、[AUTOTITLE](/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository)を参照してください。

## 組織アカウント

組織のメンバーには、_owner_⟦F9S4⟧、_billing manager_、⟦F7B5⟧または_member_のロールを設定できます。オーナーは組織に対して完全な管理者アクセス権を持ち⟦4A6C⟧、請求マネージャーは請求設定を管理できます⟦35KB⟧。メンバーは、それ以外の全員に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization)
* [AUTOTITLE](/organizations/managing-user-access-to-your-organizations-repositories/managing-repository-roles/repository-roles-for-an-organization)
* [AUTOTITLE](/organizations/organizing-members-into-teams/about-teams)

## エンタープライズアカウント

エンタープライズアカウントには、エンタープライズ設定へのユーザーのアクセスを定義する事前定義された一連のロールがあります。また、カスタムエンタープライズロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、⟦BG3W⟧ドキュメント⟦HHGW⟧の⟦96EY⟧[AUTOTITLE](/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)または[AUTOTITLE](/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦6T85⟧を参照してください。
