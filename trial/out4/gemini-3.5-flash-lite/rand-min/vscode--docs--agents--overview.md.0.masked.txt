# ⟦2Z8X⟧ で AI を使用した構築

⟦TBAS⟧ で、タスクに必要なだけの AI を自由に使用できます。入力時のサジェストの取得、コード、テスト、デバッガーの横でのエージェントとの共同作業、または ⟦N7PS⟧ でのプロジェクト間でのタスクの調整を行うことができます。作業の変更に合わせて、これらのアプローチを組み合わせます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自の API キーを使用して、⟦EE2E⟧、⟦Q9EY⟧、または ⟦J9K4⟧ のエージェントハーネスで作業します。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦P6RN⟧ を介して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用します。

[エージェント](/docs/agents/concepts/agents.md)は、モデルとツールを使用して、関連するコードの検索、変更の実行、チェックの実行を行います。⟦RBSC⟧ と ⟦V36Y⟧ の両方がエージェントを実行します。目標を設定し、作業を誘導し、結果を確認します。

ルーチンワークの場合は、プロンプトを[自動化](/docs/agents/run/automations.md)として保存します。ローカルでスケジュールに従って実行するか、クラウド自動化 `feature(cloud-automations)` を使用して、コンピューターの電源がオフの間も継続するスケジュールされた、またはイベントトリガーによるリポジトリ作業を実行します。定期的な作業を有効にする前に、手動実行を確認します。

集中的な編集を行うには、コードから離れることなく[インラインチャット](/docs/chat/inline-chat.md)を使用します。特定のタスクの機能を比較するには、[AI 機能の早見表](/docs/agents/reference/ai-features-cheat-sheet.md#choose-a-feature)を使用します。

## モデル、エージェント、およびツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](/docs/agents/quickstart.md)。ニーズの変化に応じて、以下の選択肢を適応させることができます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦SJ8D⟧ を介して[複数のプロバイダーからモデルを選択](/docs/agent-customization/language-models.md)するか、独自の[API キー (BYOK)](/docs/agent-customization/language-models.md#bring-your-own-language-model-key)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | その[ツールとワークフロー](/docs/agents/run/agent-harnesses.md#compare-agent-harnesses)に基づいて、⟦WQGR⟧、⟦ZTF2⟧、または ⟦PZQK⟧ から選択します。 |
| **アクセスと課金** | 既存の ⟦KASS⟧ プラン、サポートされているプロバイダーアカウント、または API キーを使用します。[ハーネスの要件](/docs/agents/run/agent-harnesses.md#requirements-and-setup)を確認してください。 |
| **カスタマイズ** | [プラグイン](/docs/agent-customization/agent-plugins.md)、[プロジェクトの指示](/docs/agents/guides/customize-copilot-guide.md)、および[スキル](/docs/agent-customization/agent-skills.md)でエージェントを調整します。[Model Context Protocol (MCP) サーバー](/docs/agent-customization/mcp-servers.md)を介して外部ツールを接続します。 |

## インターフェイスとマシンをまたいだ継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシンをまたいでエージェントの作業を引き継ぐことを意味します。ワークスペースと実行はホスト上に維持したまま、エージェントとやり取りする場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦S6YZ⟧ アプリとデバイス間** | [⟦BB94⟧](/docs/agents/run/remote-agent-sessions.md#github-environments) `feature(github-environments)` を使用して開発マシンを登録し、⟦WTZ3⟧、⟦W6PC⟧、⟦WTQR⟧、GitHub.com、または GitHub Mobile からエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **マネージドクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](/docs/agents/run/cloud-sandbox-sessions.md) `feature(cloud-sessions)` を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは ⟦CEHN⟧** | ⟦6GHF⟧ で ⟦YPJK⟧、⟦JFFJ⟧、または ⟦SE3P⟧ エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](/docs/agents/run/sessions/manage-sessions.md#continue-between-the-chat-view-and-agents-window)。 |
| **別のマシンの ⟦93HE⟧** | [SSH](/docs/agents/run/remote-agent-sessions.md#connect-via-ssh) または[開発トンネル](/docs/agents/run/remote-agent-sessions.md#connect-via-dev-tunnel)を介して ⟦94S9⟧ 固有のネイティブリモート接続を使用します。開発トンネルは[ブラウザーベースの ⟦S8BZ⟧](/docs/agents/run/remote-agent-sessions.md#use-the-agents-window-in-the-browser)もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを実行状態にしてアクセス可能な状態に維持してください。クラウドセッションでは、代わりにマネージドコンピュートが使用されます。クラウドでの作業のためにクラウドセッションを開始し、そのセッションを再度開いて継続します。

独自プライベートリポジトリを使用して、[⟦F454⟧ でクラウドエージェントタスクを開始し、⟦BSP3⟧ で継続します](/docs/agents/cloud-continuity-tutorial.md) (実験的)。

ツールが実行される場所とモデルがホストされる場所は、個別の選択です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AI は、不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに反映させるかの責任は、引き続きお客様が負います。

* **統合前のレビュー。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[diff を確認して結果を検証](/docs/agents/run/review-code-edits.md)してください。
* **アクションの制御と作業の誘導。** [権限と承認](/docs/agents/run/approvals.md)を使用して、どのアクションに確認が必要かを決定します。[リクエストの誘導または停止](/docs/chat/chat-overview.md#send-messages-while-a-request-is-running)を行うことができますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Git ワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドのファイルシステムおよびネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](/docs/agents/run/agent-sandboxing.md)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティベースライン](/docs/agents/run/security.md#recommended-security-baseline)を確認してください。管理されたデバイスでは、組織が[エンタープライズ AI ポリシー](/docs/enterprise/manage-ai-settings.md)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](/docs/agents/agent-troubleshooting/faq.md#agents-are-not-available-in-chat)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](/docs/configure/accessibility/accessibility.md#accessible-view)の使用方法を確認してください。
