# ⟦L1:variables.product.prodname_vscode_shortname⟧でのAIを使用した構築

⟦L2:variables.product.prodname_vscode⟧では、タスクの必要性に応じてAIを自由な範囲で活用できます。入力中に候補を表示させたり、コード、テスト、デバッガーの横でエージェントと共同作業したり、⟦L3:variables.copilot.agents_window⟧でプロジェクト間のタスクを調整したりできます。作業の変化に合わせて、これらのアプローチを組み合わせることができます。

複数のプロバイダーのモデルから選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦L4:variables.product.prodname_copilot_short⟧、⟦L5:variables.product.prodname_anthropic_claude_short⟧、または⟦L6:variables.product.prodname_openai_codex_short⟧エージェントハーネスで作業します。ハーネスは、モデルを取り巻くツールとワークフローを提供します。カスタマイズやプラグインにより、エージェントを作業に合わせて調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦L7:variables.copilot.github_environments⟧経由で自身のマシン上のセッションに接続したり、ローカルホストをオンラインに維持することなくクラウドセッションを使用したりできます。

[エージェント](⟦U40⟧)は、モデルとツールを使用して関連コードを検索し、変更を加え、チェックを実行します。⟦L12:variables.copilot.chat_view⟧と⟦L13:variables.copilot.agents_window⟧の両方でエージェントを実行できます。目標を設定し、作業を指示し、結果を確認します。

定期的な作業の場合は、プロンプトを[automation](⟦U41⟧)として保存します。ローカルでスケジュールに従って実行するか、コンピューターがオフの間も継続するスケジュール設定またはイベントトリガーのリポジトリ作業にはクラウドautomation ⟦I34⟧を使用します。定期的な作業を有効にする前に、手動実行の結果を確認してください。

ピンポイントの編集には、コードから離れることなく[inline chat](⟦U42⟧)を使用します。特定のタスクに応じた機能を比較するには、[AI機能チートシート](⟦U43⟧)を使用します。

## モデル、エージェント、ツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用](⟦U44⟧)します。ニーズの変化に応じて、以下の選択肢を適宜変更できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦L14:variables.product.prodname_copilot⟧を通じて[複数のプロバイダーのモデル](⟦U45⟧)を選択するか、独自の[APIキー（BYOK）](⟦U46⟧)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](⟦U47⟧)に基づいて、⟦L15:variables.product.prodname_copilot_short⟧、⟦L16:variables.product.prodname_anthropic_claude_short⟧、または⟦L17:variables.product.prodname_openai_codex_short⟧から選択します。 |
| **アクセスと請求** | 既存の⟦L18:variables.product.prodname_copilot⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦U48⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦U49⟧)、[プロジェクト手順](⟦U50⟧)、および[スキル](⟦U51⟧)を使用してエージェントをカスタマイズします。[Model Context Protocol (MCP) サーバー](⟦U52⟧)を介して外部ツールを接続します。 |

## インターフェイスとマシン間での継続

継続性機能とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。エージェントのワークスペースと実行環境はホスト上に保持したまま、エージェントとやり取りする場所を選択できます。セッションのサポートと要件は、ハーネスと宛先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦L19:variables.product.prodname_copilot_short⟧アプリやデバイス間** | [⟦L20:variables.copilot.github_environments⟧](⟦U53⟧) ⟦I35⟧を使用して開発マシンを登録し、⟦L21:variables.product.prodname_vscode_shortname⟧、⟦L22:variables.copilot.github_copilot_app⟧、⟦L23:variables.copilot.copilot_cli_short⟧、GitHub.com、またはGitHub Mobileからそのエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **マネージドクラウドコンピュート上** | 自身のマシンをオンラインに維持することなく対話型エージェント作業を行うには、[クラウドセッション](⟦U54⟧) ⟦I36⟧を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境内にとどまり、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦L24:variables.copilot.agents_window⟧** | ⟦L28:variables.product.prodname_vscode_shortname⟧で⟦L25:variables.product.prodname_copilot⟧、⟦L26:variables.product.prodname_anthropic_claude_short⟧、または⟦L27:variables.product.prodname_openai_codex_short⟧エージェントハーネスを使用し、[インターフェイス間でセッションを継続](⟦U55⟧)します。 |
| **別のマシン上の⟦L29:variables.product.prodname_vscode_shortname⟧** | [SSH](⟦U56⟧)または[dev tunnel](⟦U57⟧)経由で⟦L30:variables.product.prodname_vscode_shortname⟧固有のリモート接続を使用します。Dev tunnelは[ブラウザベースの⟦L31:variables.copilot.agents_window⟧](⟦U58⟧)もサポートしています。 |

自身のマシン上で実行されるセッションの場合は、ホストを実行状態のままアクセス可能にしておいてください。クラウドセッションでは代わりにマネージドコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、そのセッションを再度開いて続行します。

自身のプライベートリポジトリを使用して、[⟦L32:variables.product.prodname_vscode_shortname⟧でクラウドアカウントタスクを開始し、⟦L33:variables.copilot.copilot_cli_short⟧で継続](⟦U59⟧)します（試験的）。

ツールを実行する場所とモデルがホストされている場所は別個の選択肢です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## コントロールの維持

AIは誤ったコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに取り込むかを決定する責任は、引き続きお客様にあります。

* **統合前の確認。** エージェントは編集内容をセッションフォルダーまたはworktreeに直接保存できます。変更をコミットまたはマージする前に、[diffを確認して結果を検証](⟦U60⟧)してください。
* **アクションの制御と作業の方向転換。** [権限と承認](⟦U61⟧)を使用して、確認を必要とするアクションを決定します。[リクエストの誘導や停止](⟦U62⟧)が可能ですが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Git worktreeはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムおよびネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦U63⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティベースライン](⟦U64⟧)を確認してください。管理対象デバイスでは、組織が[エンタープライズAIポリシー](⟦U65⟧)を通じて利用可能なエージェント、モデル、ツールを制限している場合があります。エージェントがチャットに表示されない場合は、[可用性のトラブルシューティング手順](⟦U66⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョンのワークフローについては、[Accessible Viewやその他のアクセシビリティ機能](⟦U67⟧)の使用方法を参照してください。
