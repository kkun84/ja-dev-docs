## 2026年11月12日

* テキストファイル、Markdown ドキュメント、チャット、統合ブラウザータブを作成するためのエディタータブバーの **+** メニューを追加します。 _[#347849: Experimental new tab (+) button in the editor tab bar](⟦46X8⟧)_
* コードの生成、チャットの開始、言語の選択、または無題のファイルを別のエディターで再度開くためのアクションを追加します。 _[#347848: Experiment: show a list of actions in the hint of new untitled files](⟦EFH3⟧)_
* チャットに貼り付けられた画像に、可能な場合はそのソースファイルにちなんだ名前を付けます。 _[#347828: Chat: name pasted images after their source file](⟦7SBG⟧)_
* 類似プロジェクト間の移動を減らすため、Agents ウィンドウの **Open Folder** ダイアログを選択したローカルフォルダーの親から開始します。 _[#335652: Choose Folder: Make parent folder of current folder the starting point](⟦69PF⟧)_
* Agents ウィンドウのクリーンアップエディターで、ツールバーメニューを使用してワークツリーのフィルターと並べ替えを行います。 _[#347138: Controls area for worktree cleanup could use some design love](⟦K8XE⟧)_
* HTML および CSS ファイルの単行 ⟦M4QN⟧ コメントのミニマップセクションヘッダーを表示します。 _[#210637: Minimap section headers are not shown for regions in HTML and CSS](⟦HBE4⟧)_
* [ローカル拡張機能の開発](⟦ZYAH⟧)中に、エディターおよび Agents ウィンドウのタイトルバーにボタンを追加するための提案された ⟦JB8F⟧ API を追加します。 _[#347839: Proposed API: let extensions contribute buttons to the title bar of the editor and Agents windows](⟦XRNY⟧)_
* 実験的な **AI Usage Statistics** ステータスバーウィジェットを削除します。 _[#340001: Remove the AI Usage Statistics widget](⟦5D7N⟧)_

## 2026年11月11日

* 両方のウィンドウが同じエージェントホストを使用している場合、Agents ウィンドウと WSL、Remote - SSH、または Dev Containerのエディターウィンドウの間でエージェントセッションを共有します。 _[#346859: Share agent host sessions between the Agents Window and WSL, SSH and Dev Container editor windows](⟦9WDG⟧)_
* 互換性のある受信トレイカテゴリ間でセッションをドラッグして、ピン留め、保留、クリア、アーカイブ、または再開します (実験的)。 _[#346934: Inbox mode: Sessions cannot be dragged between groups](⟦EF6J⟧)_
* すべてのウェブリンクを統合ブラウザーで開くことを有効にします。 _[#316528: Option to open all links in Integrated Browser](⟦KYS7⟧)_

## 2026年11月10日

* 受信トレイモードで対象となるセッション用のインラインの **Merge Pull Request** アクションを追加します (実験的)。 _[#346936: Inbox mode: Ready to Merge sessions have no inline Merge action](⟦F5HQ⟧)_
* **Inbox** を表示したまま、受信トレイモードで空のカテゴリを非表示にします (実験的)。 _[#346938: Inbox mode: Empty sections take up too much vertical space](⟦JBND⟧)_
* Agents ウィンドウで Compare Models (プレビュー) の親チャットにマウスオーバーして、その元の設定を確認します。 _[#347109: Model compare: show original settings on hover of the parent chat](⟦QXQD⟧)_
* セッション復元のリマインダーを維持しながら、ワークツリークリーンアップの確認メッセージを短縮します。 _[#347134: Worktree cleanup confirmation is unncessarily wordy](⟦6NWX⟧)_
* Markdown エディターでの折りたたみ可能な ⟦NMPQ⟧ セクションのサポートを追加します (実験的)。 _[#347433: Markdown editor: render ⟦VCXC⟧/⟦MB4F⟧ as collapsible sections](⟦W9JS⟧)_
* チャット入力の上にピン留めされたチャットファイルを表示する機能のサポートを追加します (実験的)。 _[#345427: Let extensions dock views above the chat input](⟦WWVG⟧)_
* VS Code ペットを非表示にするコンテキストメニューオプションを追加します (実験的)。 _[#346510: Remove option for vscode-pet](⟦44B8⟧)_
* ワークスペースおよび実行環境で受信トレイセッションをフィルターします (実験的)。 _[#347488: Add workspace and environment scope pickers to Inbox](⟦GAWV⟧)_
