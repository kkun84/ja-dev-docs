# <x id="2Z8X"/> で AI を活用したビルド

<x id="TBAS"/> では、タスクに必要な分だけ、または必要な範囲で AI を使用できます。入力に応じたサジェスト機能を利用したり、コード、テスト、デバッガーの横でエージェントと共同作業したり、<x id="N7PS"/> でプロジェクトをまたいだタスクの調整を行ったりできます。作業の変化に合わせて、これらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自の API キーを使用して、<x id="EE2E"/>、<x id="Q9EY"/>、または <x id="J9K4"/> エージェントハーネスで作業します。ハーネスは、モデルの周囲のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。<x id="P6RN"/> を使用して自分のマシンのセッションに接続するか、ローカルのホストをオンラインに保たずにクラウドセッションを使用します。

[エージェント](<x id="T33Z"/>)は、モデルとツールを使用して関連コードを見つけ、変更を加え、チェックを実行します。<x id="RBSC"/> と <x id="V36Y"/> の両方がエージェントを実行します。あなたが目標を設定し、作業を誘導し、結果を確認します。

ルーチンワークの場合は、プロンプトを[自動化](<x id="WKPQ"/>)として保存します。スケジュールに従ってローカルで実行するか、クラウド自動化 <x id="EK78"/> を使用して、コンピュータの電源がオフの間も継続するスケジュールまたはイベントトリガーのリポジトリ作業を行います。定期的な作業を有効にする前に、手動実行を確認してください。

集中的な編集を行うには、コードから離れずに[インラインチャット](<x id="D729"/>)を使用します。特定のタスクの機能を比較するには、[AI 機能のチートシート](<x id="6MSG"/>)を使用します。

## モデル、エージェント、およびツールを選択する

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用します](<x id="5YED"/>)。ニーズの変化に応じて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | <x id="SJ8D"/> を介して[複数のプロバイダーのモデル](<x id="2K9G"/>)を選択するか、独自の[API キー (BYOK)](<x id="2G7W"/>) またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | [ツールとワークフロー](<x id="F8PY"/>)に基づいて、<x id="WQGR"/>、<x id="ZTF2"/>、または <x id="PZQK"/> から選択します。 |
| **アクセスと課金** | 既存の <x id="KASS"/> プラン、サポートされているプロバイダーのアカウント、または API キーを使用します。[ハーネスの要件](<x id="3VFZ"/>)を確認してください。 |
| **カスタマイズ** | [プラグイン](<x id="ZAHM"/>)、[プロジェクト指示](<x id="KN9D"/>)、および[スキル](<x id="RXR4"/>)でエージェントを調整します。[Model Context Protocol (MCP) サーバー](<x id="EFVG"/>)を介して外部ツールを接続します。 |

## インターフェイスとマシン間で継続する

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行環境がホストに残った状態で、エージェントと対話する場所を選択できます。セッションのサポートや要件は、ハーネスや宛先によって異なります。

| 作業する場所 | ここから開始 |
|------------------------|------------|
| **<x id="S6YZ"/> アプリとデバイス間** | [<x id="BB94"/>](<x id="PVXA"/>) <x id="CGBS"/> を使用して開発マシンを登録し、<x id="WTZ3"/>、<x id="W6PC"/>、<x id="WTQR"/>、GitHub.com、または GitHub Mobile からエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに保たずにインタラクティブなエージェント作業を行うには、[クラウドセッション](<x id="DGYQ"/>) <x id="RN2H"/> を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは <x id="CEHN"/>** | <x id="6GHF"/> で <x id="YPJK"/>、<x id="JFFJ"/>、または <x id="SE3P"/> エージェントハーネスを使用し、[インターフェイス間でセッションを継続します](<x id="J2E3"/>)。 |
| **別のマシンの <x id="93HE"/>** | [SSH](<x id="Z3KM"/>) または[開発トンネル](<x id="9BA3"/>)を介した <x id="94S9"/> 固有のリモート接続を使用します。開発トンネルは[ブラウザーベースの <x id="S8BZ"/>](<x id="N5SB"/>) もサポートしています。 |

自分のマシンで実行されるセッションの場合は、ホストを稼働させ、アクセス可能な状態に保ってください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、後でそのセッションを再度開いて継続します。

独自 プライベートリポジトリを使用して、[<x id="F454"/> でクラウドエージェントタスクを開始し、<x id="BSP3"/> で継続します](<x id="VZHH"/>)（実験的）。

ツールが実行される場所とモデルがホストされる場所は別々の選択肢です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御を維持する

AI は、不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに取り入れるかを決定する責任は、あなたが負います。

* **統合する前にレビューする。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[diff を確認し、結果を検証してください](<x id="SM5W"/>)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](<x id="FWCJ"/>)を使用して、確認を必要とするアクションを決定します。[リクエストを誘導または停止する](<x id="P6F9"/>)ことができますが、停止しても完了したアクションや外部サービスへの変更は取り消されません。
* **分離の理解。** Git ワークチームはコード変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](<x id="4VYH"/>)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](<x id="HZ7E"/>)を確認してください。管理されたデバイスでは、組織が[エンタープライズ AI ポリシー](<x id="BWHV"/>)を通じて、利用可能なエージェント、モデル、およびツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](<x id="3BPX"/>)を確認してください。

キーボード、スクリーンリーダー、およびロービジョン用のワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](<x id="HG5N"/>)の使用方法を確認してください。
