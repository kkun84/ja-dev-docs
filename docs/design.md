# 設計

2026-11-16に作り直した設計です。この文書が、このリポジトリの設計の正本です。2026-11-11に書いた他の設計メモは、この文書と食い違う箇所ではこの文書を優先します。

料金と無料枠の上限は、2026-11-16に確認した値です。

## 目的

VS CodeとGitHubの公式ドキュメントを、日本語で読めるサイトとして公開します。

- VS Codeのドキュメントには、公式の日本語版がありません。
- GitHub Docsには公式の日本語版がありますが、表や太字などの書式が崩れたページと、未訳のページがあります。

## 読者

自分と身近な人が読むことを前提にします。サイトは誰でも読める形で公開します。

## 予算

翻訳にはお金を使いません。

- 翻訳には、無料枠のあるAPIと、無償で使えるオープンウェイトのモデルだけを使います。
- 残高の入金や支払い方法の登録が条件になる無料枠は使いません。

ドメインの費用は未決です。

## リポジトリ

設計メモ、サイトのコード、訳文、翻訳とビルドのワークフローを、すべて公開リポジトリ`kkun84/ja-dev-docs`に置きます。

公開にするのは、GitHub Actionsの標準ランナーを、時間の上限なしに無料で使うためです。Actionsでサイトをビルドするので、サイトのコードも同じリポジトリに置きます。訳文も原文もCC BYの公開文書なので、公開して困る中身はありません。APIキーはGitHubのシークレットとCloudflareのシークレットに置きます。

設計メモだけを非公開のリポジトリに分ける案は採りません。非公開に残るのが設計メモだけになり、分ける利点が小さいためです。

## ホスティング

Cloudflare Pagesの無料プランで公開します。

- 静的ファイルの配信は、リクエスト数も帯域も無制限です。
- 1サイトあたり2万ファイルが上限です。モデルごとの訳文は1ページのHTMLにまとめて入れ、ファイル数をページ数と同じに抑えます。
- 翻訳リクエストと投票のボタンは、Cloudflare WorkersとD1で作ります。Workersの無料プランは1日10万リクエストまでです。
- サイトは、GitHub Actionsでビルドし、Wranglerで直接アップロードして公開します。直接アップロードは、Cloudflare Pagesの無料プランのビルド回数(月500回)に数えられません。

## 対象範囲

| 対象 | 原文 | 訳す範囲 |
| --- | --- | --- |
| VS Code | [microsoft/vscode-docs](https://github.com/microsoft/vscode-docs) | 全ページ |
| GitHub Docs | [github/docs](https://github.com/github/docs) | 公式日本語版が崩れているページと、未訳のページ |

## 提供の形

- 対象の全ページのURLを、最初から用意します。URLは原文の構成に合わせます。
- 未翻訳のページには、英語の原文と、翻訳をリクエストするボタンを表示します。
- 1ページにつきURLは1つです。

## 翻訳の進め方

翻訳は2層に分けます。

1. 1日の上限が大きい無料モデルで、対象の全ページを訳します。
2. 1日の上限が小さい無料モデルの訳を、要望の多いページから順に追加します。

翻訳は、順番待ちの列から自動で順に行います。

1. 読者が翻訳リクエストのボタンを押すと、Cloudflare WorkersがD1の順番待ちの列に記録します。同じページへのリクエストはまとめ、件数を数えます。
2. 記録と同時に、WorkersがGitHub Actionsのワークフローを起動します。すでに実行中なら起動せず、実行中のジョブが列の続きを拾います。
3. Actionsは、リクエストの多い順、同数なら古い順に訳します。無料枠の1分あたりと1日あたりの上限を守り、その日の上限に達したら止まります。残りは翌日に自動で再開します。
4. 訳し終えたら構造検査を通し、訳文をコミットし、サイトをビルドして公開します。

順番待ちの列は、Cloudflare QueuesではなくD1に置きます。Queuesの無料プランはメッセージの保持が24時間までで、翌日に持ち越したリクエストが消えるおそれがあるためです。

翻訳はAPIの呼び出しとして行い、ページのアクセスの瞬間には訳しません。botの巡回で無料枠を使い切るのを防ぐためです。

無料枠が廃止されたモデルは、その時点で翻訳の追加を止めます。作成済みの訳文は残します。

原文は公開文書なので、入出力が学習に使われる無料枠の利用を許容します。

## 訳文のモデルを切り替える

読者は、ページごとに、どのモデルの訳文を読むかを選べます。

- 訳文は、モデルごとに別のファイルで持ちます。
- 各ファイルに、モデルのID、設定値、翻訳元のコミット、翻訳日を記録します。
- 各ページに、既定のモデルを1つ決めます。
- 読者が切り替えた選択は、ブラウザに保存します。
- 切り替えはページ内で行い、モデルごとにURLを分けません。モデルごとにURLを分けると、検索結果に同じ内容のページが並びます。
- サイト内検索の対象は、既定の訳だけです。
- 構造検査に通らなかった訳は、選択肢に出しません。
- 各ページに「この訳が読みやすい」のボタンを置き、票の多いモデルをそのページの既定にします。

## モデルの候補

無料で使えるモデルは次の4つです。

| モデル | 無料で使える範囲 | 学習利用 | 役割の案 |
| --- | --- | --- | --- |
| Gemini 3.5 Flash-Lite 無料枠 | 1日500リクエスト | あり | 全ページの翻訳 |
| Gemini 3.8 Flash 無料枠 | 1日20リクエスト | あり | 要望の多いページの翻訳 |
| PLaMo 3.1 Prime 無料プラン | 24時間で50回 | あり | 要望の多いページの翻訳 |
| PLaMo 3 Translate 8B | 手元のPCで動かせば上限なし | なし | 全ページの翻訳 |

- Geminiの無料枠の上限は、プロジェクトごとに違うという報告があります。実際の値は、APIキーを作ってから確かめます。
- PLaMo 3 Translate 8Bは、非商用であれば登録なしで無償利用できます。動かすには手元のPCのGPUが必要です。
- PLaMo 3.1 Primeの無料プランは、利用者の登録が必要です。24時間で50回という上限は、[PLaMo APIの料金プラン](https://plamo.preferredai.jp/api)の記載です。[制限事項](https://docs.plamo.preferredai.jp/ja/limit)のページには、無料プランのPrimeの上限が載っていません。実際の上限は、登録してから確かめます。

## 品質の担保

- コードブロック、リンク、Liquidタグは、訳す前に退避し、訳した後に戻します。
- 訳した後に、見出し、リスト、表、コードブロックの構造が原文と一致するかを、プログラムで検査します。
- 同じ検査で、リンクと画像も確かめます。リンク先のURLと画像のパスが原文と一致すること、内部リンクのアンカーが訳文側に存在することを見ます。退避したリンクをモデルが落とすと、構造が一致していてもリンク切れになるためです。
- 見出しのアンカーIDは、訳文でも原文の見出しから作ったIDのまま残します。見出しを訳すとIDが変わり、原文のIDを指す内部リンクが切れるためです。訳文の見出しには、原文のIDを明示的に付けます。
- リントは、この構造検査だけから始めます。文体や用語の規則は、実際の訳文で問題が出てから足します。
- 文体と用語は、[訳し方の指針と用語集](translation-guidelines.md)の決定事項に従います。

## 原文への追従

- 原文のリポジトリの差分を定期的に取り込みます。
- 訳済みのページは、変更があった部分だけを再翻訳します。
- 再翻訳が済むまでは、訳が古い旨をページに表示します。
- 未翻訳のページは、表示する英語の原文を更新します。
