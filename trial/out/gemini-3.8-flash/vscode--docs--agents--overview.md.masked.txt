# ⟦L1:variables.product.prodname_vscode_shortname⟧でAIを活用して構築する

⟦L2:variables.product.prodname_vscode⟧では、タスクの必要性に応じてAIを必要なだけ活用できます。入力しながらサジェストを受け取ったり、コード、テスト、デバッガーの横でエージェントと共同作業したり、⟦L3:variables.copilot.agents_window⟧でプロジェクト間のタスクを調整したりできます。作業の変化に合わせてこれらのアプローチを組み合わせることができます。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦L4:variables.product.prodname_copilot_short⟧、⟦L5:variables.product.prodname_anthropic_claude_short⟧、または⟦L6:variables.product.prodname_openai_codex_short⟧のエージェントハーネスで作業します。ハーネスは、モデルを取り巻くツールとワークフローを提供します。カスタマイズやプラグインにより、エージェントを作業に合わせて調整できます。

Continuityにより、最初からやり直すことなく、サポートされているインターフェース間でエージェントの作業を引き継ぐことができます。⟦L7:variables.copilot.github_environments⟧を通じて自身のマシン上のセッションに接続するか、ローカルホストをオンラインに保たずにクラウドセッションを使用します。

[エージェント](⟦U40⟧)は、モデルとツールを使用して関連するコードを見つけ、変更を加え、チェックを実行します。⟦L12:variables.copilot.chat_view⟧と⟦L13:variables.copilot.agents_window⟧の両方でエージェントが実行されます。ユーザーは目標を設定し、作業を指示し、結果を確認します。

定常的な作業には、プロンプトを[オートメーション](⟦U41⟧)として保存します。スケジュールに従ってローカルで実行するか、コンピューターがオフの間も継続するスケジュール設定またはイベントトリガーによるリポジトリ作業にクラウドオートメーション⟦I34⟧を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

集中的な編集には、コードから離れることなく[inline chat](⟦U42⟧)を使用します。特定のタスクの機能を比較するには、[AI機能チートシート](⟦U43⟧)を使用します。

## モデル、エージェント、ツールの選択

最初のエージェントタスクでは、すべてのオプションを設定せずに[クイックスタートを使用](⟦U44⟧)します。ニーズの変化に応じて、以下の選択肢を調整できます。

| 選択肢 | オプション |
|--------|---------|
| **Models** | ⟦L14:variables.product.prodname_copilot⟧を通じて[複数のプロバイダーのモデルを選択](⟦U45⟧)するか、独自の[APIキー（BYOK）](⟦U46⟧)またはサポートされているローカルモデルを使用します。 |
| **Agent harnesses** | [ツールとワークフロー](⟦U47⟧)に基づいて、⟦L15:variables.product.prodname_copilot_short⟧、⟦L16:variables.product.prodname_anthropic_claude_short⟧、または⟦L17:variables.product.prodname_openai_codex_short⟧から選択します。 |
| **Access and billing** | 既存の⟦L18:variables.product.prodname_copilot⟧プラン、サポートされているプロバイダーアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦U48⟧)を確認してください。 |
| **Customization** | [プラグイン](⟦U49⟧)、[プロジェクトの手順](⟦U50⟧)、[スキル](⟦U51⟧)を使用してエージェントをカスタマイズします。[Model Context Protocol（MCP）サーバー](⟦U52⟧)を介して外部ツールを接続します。 |

## インターフェースやマシンをまたいで継続する

Continuityとは、最初からやり直すことなく、サポートされているインターフェースやマシン間でエージェントの作業を引き継ぐことを意味します。エージェントのワークスペースと実行をホスト上に維持したまま、エージェントとやり取りする場所を選択します。セッションのサポート状況と要件は、ハーネスおよび接続先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦L19:variables.product.prodname_copilot_short⟧アプリやデバイス間** | [⟦L20:variables.copilot.github_environments⟧](⟦U53⟧)⟦I35⟧を使用して開発マシンを登録し、⟦L21:variables.product.prodname_vscode_shortname⟧、⟦L22:variables.copilot.github_copilot_app⟧、⟦L23:variables.copilot.copilot_cli_short⟧、GitHub.com、またはGitHub Mobileからそのエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **マネージドクラウドコンピュート上** | 自身のマシンをオンラインに保たずにインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦U54⟧)⟦I36⟧を使用します。既存のクラウドセッションを再度開いて会話を続けます。実行はクラウド環境内にとどまり、その可用性と有効期間はサービスによって管理されます。 |
| **エディターまたは⟦L24:variables.copilot.agents_window⟧** | ⟦L28:variables.product.prodname_vscode_shortname⟧で⟦L25:variables.product.prodname_copilot⟧、⟦L26:variables.product.prodname_anthropic_claude_short⟧、または⟦L27:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを使用し、[インターフェース間でセッションを継続](⟦U55⟧)します。 |
| **別のマシン上の⟦L29:variables.product.prodname_vscode_shortname⟧** | [SSH](⟦U56⟧)または[dev tunnel](⟦U57⟧)を介した⟦L30:variables.product.prodname_vscode_shortname⟧固有のリモート接続を使用します。Dev tunnelは[ブラウザーベースの⟦L31:variables.copilot.agents_window⟧](⟦U58⟧)もサポートしています。 |

自身のマシンで実行されるセッションの場合は、ホストを実行状態にし、到達可能な状態に保ってください。クラウドセッションでは代わりにマネージドコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、そのセッションを再度開いて継続します。

独自のプライベートリポジトリを使用して、[⟦L32:variables.product.prodname_vscode_shortname⟧でクラウドエージェントタスクを開始し、⟦L33:variables.copilot.copilot_cli_short⟧で継続](⟦U59⟧)します（Experimental）。

ツールがどこで実行されるかと、モデルがどこでホストされているかは個別の選択肢です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御を維持する

AIは誤ったコードを生成したり、意図を誤解したりすることがあります。どの変更をコードベースに反映するかを決定する責任は、引き続きユーザーにあります。

* **統合前のレビュー。** エージェントは編集内容をセッションフォルダーまたはworktreeに直接保存できます。変更をコミットまたはマージする前に、[diffを確認して結果を検証](⟦U60⟧)してください。
* **アクションの制御と作業の方向転換。** [権限と承認](⟦U61⟧)を使用して、どのアクションに確認が必要かを決定します。[リクエストを誘導または停止](⟦U62⟧)できますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Gitのworktreeはコード変更を分離して保持しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムおよびネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦U63⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティベースライン](⟦U64⟧)を確認してください。管理対象デバイスでは、組織が[エンタープライズAIポリシー](⟦U65⟧)を通じて利用可能なエージェント、モデル、ツールを制限している場合があります。エージェントがチャットに表示されない場合は、[可用性のトラブルシューティング手順](⟦U66⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[Accessible Viewやその他のアクセシビリティ機能](⟦U67⟧)の使用方法を確認してください。
