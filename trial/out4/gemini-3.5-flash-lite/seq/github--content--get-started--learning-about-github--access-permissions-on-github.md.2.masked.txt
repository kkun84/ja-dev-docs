## ⟦L1:variables.product.github⟧でのアクセス権限について

⟦L2:reusables.organizations.about-roles⟧

ロールの仕組みは、アカウントの種類によって異なります。アカウントの詳細については、[AUTOTITLE](⟦U11⟧)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリ所有者_と_コラボレーター_の2つの権限レベルがあります。詳細については、[AUTOTITLE](⟦U12⟧)を参照してください。

## 組織アカウント

組織のメンバーには、_所有者_⟦L3⟧、_請求管理者_⟦L4⟧、または_メンバー_のロールを割り当てることができます。所有者は組織に対する完全な管理者アクセス権を持ち、請求管理者は請求設定を管理できます⟦L6⟧。メンバーは、それ以外の全員に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](⟦U13⟧)
* [AUTOTITLE](⟦U14⟧)
* [AUTOTITLE](⟦U15⟧)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセス権を定義する、あらかじめ定義されたさまざまなロールがあります。また、カスタムのエンタープライズロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、⟦L7⟧⟦L8:variables.product.prodname_ghe_cloud⟧ドキュメントの[AUTOTITLE](⟦U16⟧)⟦L9⟧[AUTOTITLE](⟦U17⟧)⟦L10⟧を参照してください。
