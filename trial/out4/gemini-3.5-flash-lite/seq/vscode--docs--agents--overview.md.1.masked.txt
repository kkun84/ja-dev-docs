# ⟦L1:variables.product.prodname_vscode_shortname⟧でのAIによるビルド

⟦L2:variables.product.prodname_vscode⟧では、タスクに必要な分だけAIを活用できます。入力に応じたサジェスト機能の取得、コード、テスト、デバッガーの横でのエージェントとの協業、あるいは⟦L3:variables.copilot.agents_window⟧でのプロジェクトをまたいだタスクの調整などが行えます。作業の変化に応じて、これらのアプローチを組み合わせてください。

複数のプロバイダーからモデルを選択し、サポートされているアカウントまたは独自のAPIキーを使用して、⟦L4:variables.product.prodname_copilot_short⟧、⟦L5:variables.product.prodname_anthropic_claude_short⟧、または⟦L6:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを利用できます。ハーネスは、モデル周辺のツールとワークフローを提供します。カスタマイズやプラグインにより、作業に合わせてエージェントを調整できます。

継続性機能により、最初からやり直すことなく、サポートされているインターフェイス間でエージェントの作業を引き継ぐことができます。⟦L7:variables.copilot.github_environments⟧を介して自分のマシンのセッションに接続するか、ローカルホストをオンラインに維持せずにクラウドセッションを使用できます。

[エージェント](⟦U40⟧)は、モデルとツールを使用して関連コードの検索、変更の適用、チェックの実行を行います。⟦L12:variables.copilot.chat_view⟧と⟦L13:variables.copilot.agents_window⟧の両方でエージェントが実行されます。あなたが目標を設定し、作業を導き、結果を確認します。

定型作業の場合は、プロンプトを[自動化](⟦U41⟧)として保存します。ローカルでスケジュール実行するか、コンピューターの電源がオフの間も継続するスケジュールまたはイベントトリガーによるリポジトリ作業には、クラウド自動化⟦I34⟧を使用します。定期的な作業を有効にする前に、手動実行を確認してください。

集中的な編集を行うには、コードから離れることなく[インラインチャット](⟦U42⟧)を使用します。特定のタスクの機能を比較するには、[AI機能の早見表](⟦U43⟧)を使用します。

## モデル、エージェント、およびツールの選択

最初のエージェントタスクでは、すべてのオプションを設定することなく[クイックスタートを使用します](⟦U44⟧)。ニーズの変化に応じて、以下の選択肢を適応させることができます。

| 選択肢 | オプション |
|--------|---------|
| **モデル** | ⟦L14:variables.product.prodname_copilot⟧を介して[複数のプロバイダーのモデル](⟦U45⟧)を選択するか、独自の[APIキー（BYOK）](⟦U46⟧)またはサポートされているローカルモデルを使用します。 |
| **エージェントハーネス** | その[ツールとワークフロー](⟦U47⟧)に基づいて、⟦L15:variables.product.prodname_copilot_short⟧、⟦L16:variables.product.prodname_anthropic_claude_short⟧、または⟦L17:variables.product.prodname_openai_codex_short⟧から選択します。 |
| **アクセスと課金** | 既存の⟦L18:variables.product.prodname_copilot⟧プラン、サポートされているプロバイダーのアカウント、またはAPIキーを使用します。[ハーネスの要件](⟦U48⟧)を確認してください。 |
| **カスタマイズ** | [プラグイン](⟦U49⟧)、[プロジェクトの手順](⟦U50⟧)、[スキル](⟦U51⟧)を使用してエージェントを調整します。[Model Context Protocol（MCP）サーバー](⟦U52⟧)を介して外部ツールを接続します。 |

## インターフェイスとマシンの間での継続

継続性とは、最初からやり直すことなく、サポートされているインターフェイスやマシン間でエージェントの作業を引き継ぐことを意味します。ワークスペースと実行はホスト上に維持したまま、エージェントとやり取りする場所を選択します。セッションのサポートと要件は、ハーネスや宛先によって異なります。

| 作業したい場所 | ここから開始 |
|------------------------|------------|
| **⟦L19:variables.product.prodname_copilot_short⟧のアプリとデバイス間** | [⟦L20:variables.copilot.github_environments⟧](⟦U53⟧) ⟦I35⟧を使用して開発マシンを登録し、⟦L21:variables.product.prodname_vscode_shortname⟧、⟦L22:variables.copilot.github_copilot_app⟧、⟦L23:variables.copilot.copilot_cli_short⟧、GitHub.com、またはGitHub Mobileからエージェントセッションを継続します。利用可能なアクションはクライアントによって異なります。 |
| **管理されたクラウドコンピュート上** | 自分のマシンをオンラインに維持せずにインタラクティブなエージェント作業を行うには、[クラウドセッション](⟦U54⟧) ⟦I36⟧を使用します。既存のクラウドセッションを再度開いて会話を継続します。実行はクラウド環境で行われ、その可用性とライフタイムはサービスによって管理されます。 |
| **エディターまたは⟦L24:variables.copilot.agents_window⟧** | ⟦L25:variables.product.prodname_copilot⟧、⟦L26:variables.product.prodname_anthropic_claude_short⟧、または⟦L27:variables.product.prodname_openai_codex_short⟧のエージェントハーネスを⟦L28:variables.product.prodname_vscode_shortname⟧で使用し、[インターフェイス間でセッションを継続します](⟦U55⟧)。 |
| **別のマシンの⟦L29:variables.product.prodname_vscode_shortname⟧** | [SSH](⟦U56⟧)または[開発用トンネル](⟦U57⟧)を介した、⟦L30:variables.product.prodname_vscode_shortname⟧固有のリモート接続を使用します。開発用トンネルは、[ブラウザーベースの⟦L31:variables.copilot.agents_window⟧](⟦U58⟧)もサポートしています。 |

自分のマシンで実行されるセッションについては、ホストを実行状態にしてアクセス可能な状態に維持してください。クラウドセッションでは、代わりに管理されたコンピュートが使用されます。クラウドでの作業用にクラウドセッションを開始し、その後そのセッションを再度開いて続行します。

自身のプライベートリポジトリを使用して、[⟦L32:variables.product.prodname_vscode_shortname⟧でクラウドエージェントタスクを開始し、⟦L33:variables.copilot.copilot_cli_short⟧でそれを継続します](⟦U59⟧)（実験的機能）。

ツールが実行される場所とモデルがホストされる場所は、個別の選択です。エージェントは、ホストされているプロバイダーにモデルリクエストを送信しながら、マシン上のファイルを編集できます。

## 制御の維持

AIは、不正確なコードを生成したり、意図を誤解したりする可能性があります。どの変更をコードベースに取り入れるかを決定する責任は、引き続きお客様にあります。

* **統合前にレビューする。** エージェントは、セッションフォルダーまたはワークツリーに直接編集内容を保存できます。変更をコミットまたはマージする前に、[差分を確認して結果を検証します](⟦U60⟧)。
* **アクションの制御と作業のリダイレクト。** [権限と承認](⟦U61⟧)を使用して、どのアクションに確認が必要かを決定します。[リクエストの誘導や停止](⟦U62⟧)を行うことができますが、停止しても完了したアクションや外部サービスへの変更は元に戻りません。
* **分離の理解。** Gitワークツリーはコードの変更を分離しますが、セキュリティ境界ではありません。エージェントが実行するターミナルコマンドに対するファイルシステムとネットワークの制限については、[プラットフォーム固有のサンドボックスオプション](⟦U63⟧)を確認してください。

既存のプロジェクトでエージェントを使用する前に、[推奨されるセキュリティ基準](⟦U64⟧)を確認してください。管理されたデバイスでは、組織が[エンタープライズAIポリシー](⟦U65⟧)を通じて、利用可能なエージェント、モデル、ツールを制限している場合があります。チャットにエージェントが表示されない場合は、[可用性のトラブルシューティング手順](⟦U66⟧)を確認してください。

キーボード、スクリーンリーダー、ロービジョン向けのワークフローについては、[アクセシブルビューおよびその他のアクセシビリティ機能](⟦U67⟧)の使用方法を確認してください。
