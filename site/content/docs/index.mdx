VS CodeとGitHubの公式ドキュメントを、日本語で読むためのサイトです。読みたいページのURLの前に、このサイトのURLを付けると開けます。まだ訳が無いページは、その場で翻訳をリクエストできます。

<Usage />

## 対象のサイト

- [Visual Studio Code Docs](https://code.visualstudio.com/docs)
- [GitHub Docs](https://docs.github.com/en)

## このサイトについて

- 訳はすべて機械翻訳です。誤りがありうるので、正確な内容は原文で確認してください。
- GitHubおよびMicrosoftとは関係のない、非公式のサイトです。
- 原文のライセンスは、GitHub DocsがCC BY 4.0、VS Codeのドキュメントが CC BY 3.0 USです。各ページの末尾に原文と翻訳の情報を載せています。
- ソースコードと訳文は [kkun84/ja-dev-docs](https://github.com/kkun84/ja-dev-docs) にあります。
