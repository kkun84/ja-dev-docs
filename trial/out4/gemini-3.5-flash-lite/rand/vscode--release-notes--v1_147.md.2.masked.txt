## 2026年11月12日

* テキストファイル、Markdownドキュメント、チャット、統合ブラウザタブを作成するためのエディタータブバーの **+** メニューを追加します。 _[#347849: Experimental new tab (+) button in the editor tab bar](⟦7XWW⟧)_
* コードの生成、チャットの開始、言語の選択、または無題のファイルを別エディターで再オープンするためのアクションを追加します。 _[#347848: Experiment: show a list of actions in the hint of new untitled files](⟦FD5D⟧)_
* チャットに貼り付けられた画像に、可能な場合はそのソースファイルにちなんだ名前を付けます。 _[#347828: Chat: name pasted images after their source file](⟦HHJF⟧)_
* 兄弟プロジェクト間での移動を減らすため、Agentsウィンドウの **Open Folder** ダイアログを、選択したローカルフォルダーの親フォルダーで開始します。 _[#335652: Choose Folder: Make parent folder of current folder the starting point](⟦RQFS⟧)_
* Agentsウィンドウのクリーンアップエディターで、ツールバーメニューを使用してワークツリーをフィルターおよびソートします。 _[#347138: Controls area for worktree cleanup could use some design love](⟦2FCE⟧)_
* HTMLおよびCSSファイルの単行の ⟦EKDY⟧ コメントのミニマップセクションヘッダーを表示します。 _[#210637: Minimap section headers are not shown for regions in HTML and CSS](⟦2T62⟧)_
* [ローカル拡張機能開発](⟦E7MN⟧)中に、エディターおよびAgentsウィンドウのタイトルバーにボタンを追加するための提案された ⟦58B8⟧ APIを追加します。 _[#347839: Proposed API: let extensions contribute buttons to the title bar of the editor and Agents windows](⟦WDAK⟧)_
* 実験的な **AI Usage Statistics** ステータスバーウィジェットを削除します。 _[#340001: Remove the AI Usage Statistics widget](⟦NAQ5⟧)_

## 2026年11月11日

* 両方のウィンドウが同じエージェントホストを使用している場合に、AgentsウィンドウとWSL、Remote - SSH、またはDev Containerエディターウィンドウの間でエージェントセッションを共有します。 _[#346859: Share agent host sessions between the Agents Window and WSL, SSH and Dev Container editor windows](⟦38B2⟧)_
* 互換性のある受信トレイカテゴリ間でセッションをドラッグして、ピン留め、保持、クリア、アーカイブ、または再開します (実験的)。 _[#346934: Inbox mode: Sessions cannot be dragged between groups](⟦KMBG⟧)_
* すべてのウェブリンクを統合ブラウザで開くことを有効にします。 _[#316528: Option to open all links in Integrated Browser](⟦T9M7⟧)_

## 2026年11月10日

* 受信トレイモードの対象セッションに対して、インラインの **Merge Pull Request** アクションを追加します (実験的)。 _[#346936: Inbox mode: Ready to Merge sessions have no inline Merge action](⟦9GYR⟧)_
* **Inbox** を表示したまま、受信トレイモードの空のカテゴリを非表示にします (実験的)。 _[#346938: Inbox mode: Empty sections take up too much vertical space](⟦G9ZE⟧)_
* AgentsウィンドウでCompare Models (プレビュー) の親チャットにマウスオーバーすると、元の設定が表示されます。 _[#347109: Model compare: show original settings on hover of the parent chat](⟦VF27⟧)_
* セッション復元のリマインダーを維持しながら、ワークツリークリーンアップの確認メッセージを短縮します。 _[#347134: Worktree cleanup confirmation is unncessarily wordy](⟦9HXB⟧)_
* Markdownエディターでの折りたたみ可能な ⟦H4QD⟧ セクションのサポートを追加します (実験的)。 _[#347433: Markdown editor: render ⟦9ZMQ⟧/⟦SJ9C⟧ as collapsible sections](⟦QQ8W⟧)_
* チャット入力の上部にピン留めされたチャットファイルを表示するサポートを追加します (実験的)。 _[#345427: Let extensions dock views above the chat input](⟦JMTJ⟧)_
* VS Codeペットを非表示にするコンテキストメニューオプションを追加します (実験的)。 _[#346510: Remove option for vscode-pet](⟦KG2J⟧)_
* ワークスペースと実行環境で受信トレイセッションをフィルターします (実験的)。 _[#347488: Add workspace and environment scope pickers to Inbox](⟦DBES⟧)_
