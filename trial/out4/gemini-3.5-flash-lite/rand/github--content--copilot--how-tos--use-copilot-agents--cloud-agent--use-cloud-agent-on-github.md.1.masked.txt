## はじめに

⟦37JR⟧ セッションは、⟦6AQP⟧ 内のさまざまな場所から開始できます。セッションが実行されたら、ブラウザから離れることなく、その進捗を監視したり、フォローアップのプロンプトで指示を与えたり、結果として得られた pull request を反復的に修正したりできます。

⟦4TSV⟧ の詳細については、[AUTOTITLE](⟦RQXK⟧) を参照してください。

また、⟦FN49⟧ を使用して、これらの同じエントリポイントからパートナーが構築したエージェントを開始することもできます。詳細については、[AUTOTITLE](⟦FQVM⟧) を参照してください。

## ⟦KHWE⟧ セッションの開始

セッションは、いくつかの異なるエントリポイントから開始できます。

* [github.com/copilot](⟦YEQZ⟧) の ⟦JV26⟧ ⟦3EK4⟧ ホームページ。
* [https://github.com](⟦FBHR⟧) にサインインしているときの ⟦AW96⟧ ⟦5X8G⟧ パーソナルダッシュボードまたは ⟦SPVB⟧ ホームページ。
* リポジトリ内の **⟦67JK⟧ Agents** タブまたはパネル。

デフォルト設定のままプロンプトをすぐに送信することも、プロンプトを送信する前にタスクに合わせてセッションを設定することもできます。

1. プロンプトボックスに、⟦QSKC⟧ に実行させたい内容を入力します。希望する成果と制約事項を含めてください。

   > [!TIP]
   > プロンプト内でスラッシュコマンドを使用して、2 番目の意見を得るための ⟦FB4N⟧、リポジトリの脆弱性をレビューするための ⟦B473⟧、セッションの使用状況情報を表示するための ⟦J5D2⟧ などの特定のアクションを実行することもできます。

1. オプションで、**⟦TFH6⟧ Attach** をクリックして、⟦AXHG⟧ にリクエストのリファレンスを提供します。

   リクエストのコンテキストを提供するには、**Files and folders**、**Upload from computer**、**Repository**、または **Space** を選択します。

   クラウドサンドボックスセッションの場合は、コネクタや個人のカスタム MCP サーバーを設定することで、サードパーティソースから追加のコンテキストを提供できます。[AUTOTITLE](⟦BFDW⟧) および [AUTOTITLE](⟦7KSK⟧) を参照してください。

1. **Mode** ピッカーを開いて、⟦TBWS⟧ とどのように共同作業を行うかを選択します。

   * **Interactive**: (デフォルト) ⟦VD7Q⟧ とステップバイステップで作業します。
   * **Autopilot**: タスクを ⟦WXE9⟧ に委任して、エンドツーエンドで実行させます。

   同じメニューで、**Tool permissions** を使用してツールリクエストの承認方法を制御します。

   * **Assisted** (デフォルト) を選択します。安全性チェックを使用して、リクエストを承認するかユーザーに確認するかを決定します。
   * **Always ask** を選択すると、リクエストごとに承認が必要になります。
   * **Allow all** を選択すると、すべてのツール、パス、および URL リクエストが自動的に承認されます。

1. **Models** ピッカーを開き、**Auto** (デフォルト) または特定のモデルを選択します。モデルは、速度と費用対効果、汎用性と知能、または複雑なタスクへの適性のいずれかを選択しやすくするために、長所ごとにグループ化されています。選択したモデルが **Balance** などの設定可能な推論をサポートしている場合は、ドロップダウンメニューを使用して推論レベルを選択することもできます。

1. プロンプトボックスの下にある **Chat** セッションコンテキストピッカーを使用して、セッションのスコープ (個人、組織、またはリポジトリ) を選択します。

   * 検索ボックスにリポジトリ名を入力して、追加するリポジトリを検索します。
   * **Ask anything across repositories** の下で **Chat** を選択すると、リポジトリ横断で質問できます。デフォルトのスコープは個人のリポジトリです。右側の画像をクリックしてアカウントメニューを開き、組織を選択するか、リポジトリ所有者 (ユーザーまたは組織) で検索してスコープを変更します。
   * **Work in a repository** の下で、作業する最近のリポジトリを選択します。リストされるリポジトリは、選択したスコープを反映しています。

   > [!NOTE]
   > * **Attach** メニュー (前のステップ) を介してリポジトリを追加すると、プロンプトのリファレンス (コンテキスト素材) が提供されます。一方、ここで **Start a session** の下で選択すると、そのリポジトリがセッションの作業用リポジトリ (スコープ) になります。セッションの開始時に、クラウドサンドボックスはそのリポジトリのコピーを取得し、既存の制約の範囲内でそのコンテンツを操作する権限を ⟦DAEC⟧ に付与します。
   > * リポジトリがリストに表示されない場合は、個人設定、組織、またはエンタープライズポリシーによって ⟦R5Z8⟧ から除外されている可能性があります。

   オプションで、上記でリポジトリを選択した場合、**main** (またはリストされているデフォルトブランチ名) をクリックして、⟦9M7F⟧ が作業コンテキストとして使用し、その中で操作するブランチを選択することもできます。

⟦DA4D⟧

1. **Send message** をクリックするか、<kbd>Enter</kbd> キーを押してプロンプトを送信し、セッションを開始します。

⟦T432⟧ はプロンプトに応答し、選択したコンテキストと環境に基づいてセッションを開始します。要求された場合、⟦ZNEY⟧ は変更されたファイルのリスト、pull request、生成された成果物 (リサーチプランなど)、およびその他の関連する出力を生成します。

## pull request での作業の継続

### ⟦EVCS⟧ への変更の依頼

⟦66Q4⟧ Web インターフェイスから pull request のコメント (レビューやレビューコメントではない) を送信する場合は、モデルピッカーでモデルを選択します。⟦HN5Q⟧ は、デフォルトで元の pull request のモデルを使用します。
