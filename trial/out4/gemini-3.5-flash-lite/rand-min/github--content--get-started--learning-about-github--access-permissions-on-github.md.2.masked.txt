## ⟦CFFA⟧ のアクセス権限について

⟦CQAD⟧

アカウントの種類によって、ロールの仕組みは異なります。アカウントの詳細については、[AUTOTITLE](/get-started/learning-about-github/types-of-github-accounts)を参照してください。

## 個人アカウント

個人アカウントが所有するリポジトリには、_リポジトリオーナー_と_コラボレーター_の2つの権限レベルがあります。詳細については、[AUTOTITLE](/repositories/managing-your-repositorys-settings-and-features/repository-access-and-collaboration/permission-levels-for-a-personal-account-repository)を参照してください。

## 組織アカウント

組織のメンバーには、_オーナー_⟦J2EZ⟧、_請求管理者_、⟦7KC9⟧、または_メンバー_のロールを設定できます。オーナーは組織に対する完全な管理者アクセス権を持ち⟦QVHY⟧、請求管理者は請求設定を管理できます⟦SKCS⟧。メンバーは、それ以外の全員に対するデフォルトのロールです。チームを使用すると、複数のメンバーのアクセス権限を一度に管理できます。詳細については、以下を参照してください。
* [AUTOTITLE](/organizations/managing-peoples-access-to-your-organization-with-roles/roles-in-an-organization)
* [AUTOTITLE](/organizations/managing-user-access-to-your-organizations-repositories/managing-repository-roles/repository-roles-for-an-organization)
* [AUTOTITLE](/organizations/organizing-members-into-teams/about-teams)

## 企業アカウント

企業アカウントには、エンタープライズ設定へのユーザーのアクセスを定義する事前定義された一連のロールがあります。また、カスタムのエンタープライズロールを作成して、独自の細かい権限セットを定義することもできます。

詳細については、⟦S9YR⟧⟦MVBR⟧ ドキュメント内の [AUTOTITLE](/enterprise-cloud@latest/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles)⟦VNCN⟧ [AUTOTITLE](/admin/managing-accounts-and-repositories/managing-roles-in-your-enterprise/abilities-of-roles) ⟦JSHK⟧ を参照してください。
